# 底盘与麦轮

## 文件和输入

`user/chassis/chassis.[ch]` 负责坐标变换、跟随/自旋斜坡和麦轮逆解；任务层决定当前模式及停车条件。输出是四轮转子目标rpm，`Motor3508_SpeedControl` 生成电流，后续功率限制在发送前执行。

## 麦轮逆解

```text
轮1 = front - left - cycle
轮2 = front + left - cycle
轮3 = -front - left - cycle
轮4 = -front + left - cycle
```

这里front/left/cycle是已缩放到轮速分量的输入，不是直接m/s和rad/s。四轮最大绝对值超过max_motor_rpm时等比例缩小，保留运动分量比例；符号和轮号必须与实车一致。

## 模式逻辑

| 模式 | 控制 |
| --- | --- |
| 机械 | 平移按上板机械Yaw角旋转到底盘坐标，旋转摇杆直接控制；角暂失效时使用最近车头方向 |
| 跟随 | 选择最近0°或±180°车头，角误差扣连续死区后乘比例，叠加Yaw输入前馈，限幅并做每周期斜坡 |
| 小陀螺 | 平移按云台角旋转，自旋目标经斜坡；明确禁止可立即清自旋；角无效时不提供云台方向平移 |
| 调头/校准锁车 | 四轮停机；调头本地预锁等上板确认，完成立即解除，未接管超时撤销 |

坐标变换：`front'=front×cosθ−left×sinθ`，`left'=front×sinθ+left×cosθ`；θ由C1角和方向系数生成。当前跟随只检查底盘IMU角速度是否有效，没有以该角速度做旋转速度PID，也没有IMU积分平移测速或防打滑控制。

电机反馈失联按轮处理：该轮持续发零电流，其他轮保留原解算目标并继续接受功率限流。恢复有效反馈后自动执行当前目标，没有重新分配三轮运动学。

## 参数、排查和移植

`chassis_config` 的缩放、最大转速、车头迟滞、follow/spin/turn字段见配置表。先核电机顺序与符号，再核C1角度、坐标变换、跟随比例和斜坡。最大转速限制不能替代功率控制。

逆解数学部分可单独提取到其他四轮麦轮工程，但当前Chassis_MecanumInverse直接调用3508驱动，其他模式还依赖通信、IMU与配置。复用整模块需适配这些接口；若只要解算，将四轮rpm计算作为独立输入输出，再交给目标工程驱动。

## 接口与排查补充

`Chassis_TurnaroundUpdate` 消费调头事件序号，收到正在调头后保持停车，结束后释放。模式切换调用 Reset 清除旧旋转斜坡；小陀螺阻止原因见 [任务模块](01_启动与任务.md)。

## 常用观察变量

四轮数组下标 0～3 对应电机 ID1～ID4。目标速度只有在 `chassis_power_state.speed_targets_valid` 为真时参与速度误差分配。

| Watch 表达式 | 单位 / 类型 | 含义 |
| --- | --- | --- |
| `chassis_front_reversed` | bool | 底盘当前采用物理车尾作为逻辑正方向。 |
| `chassis_turnaround_pending` | bool | 下板正在等待上板完成调头并保持停车。 |
| `chassis_spin_block_reason` | uint8 | 小陀螺拦截原因，数值对照见启动与任务文档。 |
| `chassis_spin_stop_count` | 次 | 自旋运行后被撤销的累计次数。 |
| `chassis_power_state.target_speed_rpm[0]` | 转子 rpm | 送入本轮闭环与功率分配的 ID1 目标速度。 |
| `chassis_power_state.speed_rpm[0]` | 转子 rpm | 模型本周期采用的 ID1 实际速度。 |
| `chassis_power_state.wheel_feedback_valid[0]` | bool | ID1 电机反馈新鲜且可用。 |
| `motor3508.data.feedback[0].position_deg` | 转子 deg | ID1 从首帧起累计的位置。 |

### 模式内部状态

以下为 `user/chassis/chassis.c` 内的静态变量。旋转分量是解算输入，实际车身角速度看底盘 IMU。

| Watch 表达式 | 单位 / 类型 | 含义 |
| --- | --- | --- |
| `chassis_follow_cycle_rpm` | 轮速 rpm | 跟随模式本周期斜坡后的旋转分量。 |
| `chassis_spin_cycle_rpm` | 轮速 rpm | 小陀螺本周期斜坡后的旋转分量。 |
| `chassis_turnaround_seen_active` | bool | 已收到上板本次调头正在执行的状态。 |

完整速查与观察方法见 [本板观察变量速查](00_观察变量速查.md)。
