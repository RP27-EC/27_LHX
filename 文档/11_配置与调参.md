# 配置与调参

## 配置入口

`user/application_config.[ch]` 管应用策略，`bottom_driven/peripheral_config.[ch]` 管驱动和外设。默认值在对应.c初始化函数中，启动时加载一次。下列字段表来自当前头文件注释；调参时以功能、单位、方向和限幅关系为依据，具体数值以当前源码或Watch为准。

配置是volatile便于调试观察，但多字段同时修改仍可能被控制任务分周期读到。调试器改值只作用于当前运行，重新启动会恢复源码默认值；确认结果后回填初始化函数。不要在周期中再次调用全部配置初始化。

## 配置对象与完整字段

### user/application_config.h

| 配置对象 | 类型 | 功能 |
| --- | --- | --- |
| `remote_config` | `RemoteConfig` | 遥控解析与转发周期参数。 |
| `keyboard_sensitivity_config` | `KeyboardSensitivityConfig` | 键鼠移动和瞄准灵敏度参数。 |
| `chassis_config` | `ChassisConfig` | 底盘解算、跟随与自旋参数。 |
| `chassis_power_config` | `ChassisPowerConfig` | 底盘功率观测的电流换算参数。 |
| `chassis_power_control_config` | `ChassisPowerControlConfig` | 超电实测功率闭环参数。 |

#### RemoteConfig

| 字段 | 类型 | 用途与单位 |
| --- | --- | --- |
| `task_period_ticks` | `uint32_t` | 对应任务的执行周期，tick。 |
| `period_ticks` | `uint32_t` | D1~D3 遥控分帧转发任务周期，tick。 |

#### KeyboardSensitivityConfig

| 字段 | 类型 | 用途与单位 |

| `slow_raw` | `int32_t` | Ctrl 慢速幅值。 |

| `mouse_pitch_gain` | `int32_t` | 鼠标 Y 灵敏度。 |
| `aim_divisor` | `int32_t` | 右键精细瞄准倍率的除数。 |

| `follow_kp_rpm_per_deg` | `float` | 死区外角度误差到旋转轮速的比例，rpm/度。 |

| `follow_ff_rpm_per_rc` | `float` | 死区外遥控旋转输入到轮速前馈的比例，rpm/通道值。 |
| `follow_max_rotate_rpm` | `float` | 跟随旋转分量绝对值上限，轮速 rpm。 |
| `follow_slew_rpm_per_tick` | `float` | 每个底盘控制周期允许的跟随轮速变化量，rpm。 |
| `yaw_rate_tx_period_ms` | `uint32_t` | 所有模式向上板发送 D4 实测底盘角速度的最短间隔。 |

## 调参顺序与移植

先确认电机/IMU方向、反馈在线与机械行程，之后内环、外环、动作轨迹和前馈。电流/转矩限幅是输出保护，速度限幅是目标约束，不能互相替代。更改RTOS周期需同步核对PID周期、斜坡每周期步长、堵转周期数与通信有效期。

可复用驱动需一起复制其配置类型、初始化函数、算法依赖和回调分发；本工程不是所有句柄/引脚都集中配置的平台框架，仍有Core及设备层固定句柄。迁移到新板时用CubeMX配置外设，再逐一核对这些固定绑定，不能仅替换参数结构体就认为移植完成。
