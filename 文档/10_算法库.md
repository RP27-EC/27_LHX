# 算法库

## PID

文件 `algorithms_library/pid/PID.[ch]`。位置式：误差=目标−实测，积分按误差×周期累加，微分按误差差/周期计算；积分状态和最终输出分别限幅。输出饱和且误差继续推向饱和时停止同向积分。`IntegralLimit` 限制的是误差积分状态，不是直接的积分输出，Ki为零或积分限幅为零不会提供稳态积分支撑。

| 字段/接口 | 用途 |
| --- | --- |
| `Kp/Ki/Kd`、`ControlTime` | 三项增益和周期，周期单位秒 |
| `Error/LastError/PreviousError` | 当前及历史误差 |
| `Integral/IntegralLimit` | 积分状态及其绝对上限 |
| `Output/OutputLimit` | 输出及最终限幅 |
| `PID_Init` | 参数初始化，同时清历史 |
| `PID_Reset` | 保留参数，清历史 |
| `PID_UpdateParameters` | 配置变化时同步参数；没有变化不周期覆盖直接修改的PID成员 |
| `PID_Calc/PID_Calc_Incremental` | 位置式/增量式，不能共用同一历史实例 |

应用PID和驱动PID输出单位不同，参数不能直接互抄。正常调参以配置对象为入口，同时观察目标、误差、输出和饱和。下板功率限流另有后级饱和积分处理，通用PID本身不知道最终电流又被缩小。

## 四元数 EKF

文件 `quaternion_ekf.[ch]`。六状态为w/x/y/z四元数和X/Y剩余陀螺零偏，陀螺传播姿态，加速度重力方向修正；固定矩阵工作区、Joseph协方差更新，不依赖HAL、FreeRTOS、外部矩阵库或动态分配。加速度残差异常时拒绝修正，仍允许陀螺预测。

配置 `quaternion_noise/bias_noise/accel_noise/fading/chi_square_threshold` 分别影响姿态过程、零偏过程、量测、协方差遗忘和残差门槛。实例中的 `q/gyro/bias/chi_square/accel_used` 对应结果与诊断。只有重力参考，不能修正绕重力方向的长期Yaw漂移，不能把加速度计当作无漂移平移测速器。

## 适用范围与移植

PID适合统一物理单位的固定周期闭环，复制.c/.h并加入构建，每个闭环独立实例。EKF适合三轴陀螺+加速度姿态融合；先统一坐标与rad/s、m/s²，再静止标定，创建静态实例，初始化后固定周期Update。当前EKF要求dt>0且不超过0.02s，低频移植需重新评估。详细噪声、返回值及移植步骤见下文。两板各有源码副本，改公共算法时同步核对。

## EKF 详细移植说明

`quaternion_ekf.[ch]` 参照样例工程 `bmi_EKF.c` 中 Wang Hongxi 的 QuaternionEKF V1.2.0。使用相同的六状态模型：四元数四项、X/Y 轴陀螺零偏两项。保留加速度残差检验、自适应增益、零偏修正限速及遗忘系数。矩阵改用固定数组计算，不依赖 CMSIS DSP、HAL、FreeRTOS 或动态内存；协方差改用 Joseph 形式更新，每次输出归一化四元数。

### 适用范围

适合带三轴陀螺仪和三轴加速度计的姿态解算，本工程用于 BMI088。当前两板各有一份相同的算法文件，可单独移植。只有重力方向量测，不能估计绕重力方向的航向零偏；Z 轴仍依赖启动时的静止标定。这里主要改善姿态融合和 X/Y 零偏估计，不是对三轴角速度再套一层低通。

### 移植步骤

1. 复制 `quaternion_ekf.c` 和 `.h`，把 `.c` 加入构建，把所在目录加入头文件路径。标准库需支持 `sqrtf`、`acosf` 等单精度数学函数。
2. 每个传感器各建一个 `QuaternionEkf` 实例，建议用静态变量。协方差和矩阵工作区保存在实例内，不能放在较小的任务栈上，也不能由多个任务同时更新同一实例。
3. 初始化时调用 `QuaternionEkf_Init(&filter, initial_q)`。四元数为 `w,x,y,z`；传入 `NULL` 从单位姿态开始收敛。重复初始化会清除在线零偏及协方差历史。
4. 将陀螺仪、加速度计转换到同一机体系，先做静止零偏标定；陀螺仪单位为 rad/s，加速度为 m/s²。
5. 调用 `QuaternionEkf_Update(&filter, &config, gyro, accel, dt)`。`dt` 单位为秒，当前接口要求大于零且不超过 0.02 s；低频系统需先评估并修改时间范围与噪声设置。
6. 返回 `true` 后读取 `filter.q`、`filter.gyro` 和诊断字段；返回 `false` 时不发布新姿态，交给设备层标记无效。没有有效重力量测时允许仅用陀螺仪预测。

### 参数

| 字段 | 用途 |
| --- | --- |
| `quaternion_noise` | 四元数过程噪声，按实际周期乘以 dt。增大后更容易接受加速度修正。 |
| `bias_noise` | 在线剩余零偏的过程噪声，按 dt 缩放。决定估计零偏的变化速度。 |
| `accel_noise` | 归一化加速度的量测噪声。增大后更依赖陀螺预测。它不是未经归一化的加速度方差。 |
| `fading` | 零偏协方差遗忘系数，需满足 `0 < fading <= 1`。它按更新次数作用，改变周期后需要复核。 |
| `chi_square_threshold` | 收敛后的加速度残差门槛，与量测噪声一起调。门槛过小可能使量测长时间被拒绝。 |

过程噪声允许非负值；量测噪声和残差门槛必须为正有限值。非法参数、非法陀螺样本或非法周期返回 `false`。

### 数据与限制

- `gyro` 是本周期陀螺测量减去更新前在线零偏的结果，与本周期姿态预测使用同一数据；`bias` 是更新后的估计值。
- `accel_used` 表示是否进行了加速度修正，拒绝量测时姿态仍按陀螺仪传播，不表示 IMU 离线。
- `chi_square` 用于观察量测残差，无有效加速度时设为零，应结合 `accel_used` 看。
- 动态加速度方向异常且已收敛时拒绝修正；稳定状态下持续拒绝达到恢复条件后重新允许收敛，与模板处理思路一致。
- 仅有比例位置/速度控制、机构间隙、振动或安装松动造成的抖动不会因更换姿态滤波自动消失。

## 两参数 RLS

文件 `algorithms_library/rls/rls2.[ch]`。用于 `y = theta[0] × x[0] + theta[1] × x[1]` 的在线辨识，状态保存在独立 `Rls2` 实例内，共用入口为 `rls2_algorithm.ops`。协方差使用 Joseph 更新，输入非法或计算失败时保留原状态。

`theta[2]` 保存参数，`covariance[2][2]` 保存不确定度，`innovation` 保存残差，`updates` 计成功次数。初始化使用两项初值和正协方差，更新使用回归向量、量测及遗忘系数。每个新量测调用一次，避免重复帧反复增强相同样本。

复制 `.c/.h`，加入源文件及头文件路径即可使用；不依赖 HAL、RTOS 或矩阵库。量测残差门槛、时间匹配及参数上下界在应用层处理。下板用于辨识底盘速度和力矩损耗，接口和配置见 [功率控制](04_功率控制.md)。

| Watch 表达式 | 单位 / 类型 | 含义 |
| --- | --- | --- |
| `motor3508.control.speed_pid[0].SetPoint` | 转子 rpm | ID1 速度目标。 |
| `motor3508.control.speed_pid[0].Error` | 转子 rpm | ID1 当前速度误差。 |
| `motor3508.control.speed_pid[0].Integral` | rpm·s | ID1 误差积分状态。 |
| `motor3508.control.speed_pid[0].Output` | C620 电流码 | ID1 速度 PID 输出。 |
| `chassis_power_model_state.estimator.theta[0]` | W/(rad/s) | RLS 速度损耗估计；[1] 为力矩平方损耗估计。 |
| `chassis_power_model_state.estimator.covariance[0][0]` | 协方差 | 第一参数估计的不确定度。 |
| `chassis_power_model_state.estimator.innovation` | W | 最近 RLS 量测残差。 |
| `chassis_power_model_state.estimator.updates` | 次 | 成功递推更新次数。 |
| `chassis_imu.ekf_chi_square` | 残差指标 | 姿态 EKF 加速度残差。 |
| `chassis_imu.ekf_accel_used` | bool | EKF 本周期接受加速度量测。 |
