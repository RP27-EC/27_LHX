# 发射机构

## 文件和分工

`user/shoot/shoot_control.[ch]` 控制摩擦轮与拨盘动作；`user/tasks/upper_tasks.c` 判断遥控、升降许可、遥控发射档位和重新布防。驱动在 `bottom_driven/motor/motor3508/motor3508.*`、`dial_motor.*`。裁判与功率控制位于下板，上板从D6接收热量，使用 `shoot_heat.[ch]` 做本地预测、冷却和校准，详见 [热量控制](11_热量控制.md)。

## 执行逻辑

### 待机与位置保持

- 保险：摩擦轮主动减速归零，停止供弹；待发：摩擦轮转动，拨盘等待供弹请求。
- 遥控和拨盘在线且拨盘未锁存解堵故障时，拨盘保持 `shoot_config.dial.hold_encoder` 指定的单圈位置，到位范围由 `shoot_config.dial.arrived_error_counts` 配置。
- 上线、单发结束、连发停止和中途停射时，按实测单圈码与累计位置换算最近一圈的固定相位目标。保持期间目标固定。
- 摩擦轮关闭、失联、摩擦轮恢复失败或升降未放行时，拨盘继续保持位置，供弹请求被拦截。拨盘自身解堵失败后则保持零电流卸力。
- 遥控或拨盘失联时拨盘输出零电流；恢复在线后重新建立固定相位目标。
- 待机保持和摩擦轮判稳暂停保持共用保持堵转检测：误差超过 `hold_block_error_counts` 和到位容差、速度低于 `block_speed_threshold_dps`、反馈电流超过 `hold_block_current_threshold`，且没有回正进展，才累计 `hold_deviation_timeout_ms`。正常回正达到 `progress_min_counts` 后清计时，低电流、小偏差和正常移动也会清计时。
- 保持堵转确认后先反向速度退让，再回原保持点。摩擦轮关闭时保持解堵仍会继续；遥控或拨盘离线时停止。暂停供弹时触发保持解堵会取消未完成发射，解堵期间的新单发事件直接消费。反向堵转、超时或次数用尽后锁存卸力，新的发射操作才能解除。保持堵转误差门槛独立于到位精度，调参时结合保持误差、速度和实际反馈电流确认。

### 摩擦轮主动停轮

保险、遥控断控和发射许可撤销后，发射任务每周期调用 `Motor3508_BrakeStop()`。两轮按各自实时转速执行目标零速的比例闭环，制动电流与当前转速反向，并受制动电流上限和驱动总限幅约束。进入停止死区后输出零电流，避免低速来回反转。

停轮期间清空原速度环积分，重新开轮从清空后的速度环启动。每轮分别检查反馈时效；未收到或已过期的轮反馈对应零电流，另一轮仍可主动制动。堵转恢复失败的故障分支保留零电流停止。

参数在 `motor3508_config.brake`：`kp` 为停轮比例增益，`current_limit_raw` 为刹车电流幅值上限，`stop_speed_rpm` 为停止死区。默认值在 `Motor3508BrakeConfig_Init()`。观察 `motor3508_brake_state.feedback_valid[]/active[]/current_raw[]`，依次检查反馈有效、主动制动和本周期电流命令；电流命令入队失败时下一周期重发。

停轮帧仍通过升降驱动的共享群组接口发送，保留升降电机槽位。主动停轮需要电调保持供电且反馈可用，完全掉电时无法施加制动力矩。实际停轮时间由摩擦轮惯量、制动增益和电流上限共同决定。

### 单发与连发

- 遥控拨轮下拨超过阈值登记首发，持续超过时间门槛转连发；右中、右上档均允许供弹。
- 单发目标在固定相位上增加 `shoot_config.dial.feed_direction × SHOOT_DIAL_ONE_BULLET_COUNTS`，完成整圈供弹后保持相同单圈位置。
- 连续单发直接叠加到当前累计位置目标。新指令到来时继续前进，中间供弹相位只用于计数；每个被接受的单发分别预留热量。`shoot_config.single_queue_limit` 限制当前一发之外可叠加的未完成数量。
- 连发供弹全程使用速度闭环，不插入位置保持帧。热量不足时以低档速度完成已预留末发，结束后回到最近一圈的固定相位；松开连发或许可撤销时立即停止供弹并建立保持目标。堵转反向退让使用速度控制，单发重装继续追原位置目标；连发退让结束直接恢复速度闭环。
- 左键按下立即自动开轮并登记一发；长按直接接管尚未完成的叠加目标，沿用已预留热量和供弹相位。松开连发后取消旧请求。双轮速度误差、相邻样本波动及持续稳定时间同时合格才正向供弹；掉速暂停并保持当前拨盘位置，恢复后继续。
- 遥控小陀螺按发射需求启动摩擦轮，空转时关轮；下拨发射后先等轮速稳定。短按松开后完成已登记单发再关轮，连发松开后关轮。遥控右中档仍保持预热，键鼠沿用F和左键开轮。

保险或许可撤销时取消供弹并保持拨盘位置，失联时发零电流。堵转保存原目标与方向，反向退让，再追目标或恢复连发。停机命令未成功入队时周期重试。拨盘离线时只允许摩擦轮待发，不供弹；所有模式都先发送拨盘帧，再发摩擦轮群组帧；关闭摩擦轮时也保持这个顺序，减少拨盘保持帧因邮箱被占而丢失。

判稳参数在 `shoot_config.friction.ready`，含 `enabled`、`tolerance_rpm`、`relative_tolerance`、`ripple_rpm`、`stable_ms`。`shoot_config.dial.recovery_max_attempts` 表示最多执行的反向退让次数；配置为三次时，成功退让后仍无法正向供弹，最多再退让至次数用尽。实际经过的供弹相位累计到 `count.single`，退让后重复经过旧相位只计一次。

每次退让后先正常给回追命令，`stuck_reload_grace_ms` 内暂缓正向堵转检测；随后重新检查。保持解堵回追共用保持堵转组合判据，正常回追清计时。单发和连发继续检查各自的电流低速、无进展判据；首次确认回追之前，比较点可随换向惯性后退修正，但不会刷新无进展时间。

恢复次数只累计连续未解除的卡滞。单发或保持回到原目标后清除；连发越过原堵点并继续前进 `recovery_clear_progress_counts` 后清除。反转和回追旧路段不清次数，下一次反转仍需重新确认堵转或无进展。

单发和回追检查向目标前进的进度：剩余误差累计缩小 `progress_min_counts` 后刷新计时。初次单发超过 `single_move_timeout_ms` 无进度，或解堵回追超过 `stuck_reload_timeout_ms` 无进度，都使用剩余退让次数进入反转。追加位置目标时保留PID状态和无进度计时。等待摩擦轮判稳时暂停进度检查并清除堵转连续计数。

连发同时检查高电流低速和编码器正向进展，任一判据满足就进入反向退让。累计正向前进达到 `continuous_progress_min_counts` 后刷新计时；超过 `continuous_move_timeout_ms` 无有效进展时，低电流卡住也会触发退让。连发进度参数独立于单发和回追的 `progress_min_counts`，时间和进度步长均须大于零。摩擦轮判稳暂停期间停止计时，恢复时扣除暂停时长，保留暂停前累计的无进展时间；停止连发或重新开始供弹时重建进度基准。

反向退让使用 `stuck_reverse_speed_dps` 速度闭环，以编码器确认实际退让量。进入退让立即尝试发送反转命令，首条命令成功入队后才开始起转宽限和退让计时；持续无法入队达到时间上限则卸力，原因码为10。沿退让方向达到 `stuck_reverse_angle_deg` 后先发零速，再回追原累计目标或继续连发。每次退让最多等待 `stuck_reverse_timeout_ms`，超时未退够则卸力。保持解堵只返回原保持点，返回过程中再次满足保持堵转组合判据，才使用剩余次数退让。

回退开始后的 `stuck_reverse_grace_ms` 用于等待起转，随后使用电流、低速和连续周期判据检测反向堵转。反向仍堵转时立即零电流卸力，取消旧目标和待执行指令。反转独立于摩擦轮判稳执行，正向回追继续等待轮速就绪。`block_confirm_ticks` 为零时关闭电流低速堵转判定，退让角度和超时检查继续执行。

故障后清除旧目标、单发锁存和排队请求；待发、关摩擦轮、遥控断控再恢复都不会自行恢复拨盘位置保持。新的单发边沿或释放后重新开启连发才解除故障，并按当前位置重建供弹相位。零电流入队失败会继续重发。解堵沿用本发的热量预留，重试不额外计热。

## 摩擦轮弹速自适应

`shoot_speed.[ch]` 根据裁判系统0x0207回传的主17mm枪管弹速调整两轮共同目标转速。下板通过D7转发，上板发射任务读取快照后调用 `ShootSpeed_Update()`，遥控和键鼠共用这条调速链路。

目标弹速为“弹速上限减速度余量”。裁判状态含有效弹速上限时直接采用，否则使用 `fallback_limit_m_s`。每收到一发新的有效测速，低于目标死区就增加一步，高于死区就减少一步，死区内保持。连续转发同一发的测速只处理一次；调速后的等待时间内消费测速序号，但暂停调整。

从 `shoot_config.friction.target_speed_rpm` 起调；开关摩擦轮保留已学习的转速，修改基础转速会重新起调。关闭自适应后使用基础转速。正常输出始终受应用上限、驱动上限和速度命令范围约束。开轮加速、堵转脉冲、恢复观察和故障期间暂停学习，堵转脉冲仍由原电流参数控制。

反馈中断或样本过期时保留当前转速。D7携带测速年龄，旧测速不能在重新开轮或调整转速后补调。当前转速稳定以后产生的新测速才用于调整。

参数位于 `shoot_config.friction.adaptive`，默认值在 `config/application_config.c` 的 `ShootSpeedConfig_Init()`：

| 参数 | 用途 |
| --- | --- |
| `enabled` | 自适应开关 |
| `step_rpm` | 每次反馈调整步长，rpm |
| `margin_m_s` | 目标弹速与上限的余量，m/s |
| `max_speed_rpm` | 正常速度控制转速上限，rpm |
| `deadband_m_s` | 目标附近保持转速的范围，m/s |
| `fallback_limit_m_s` | 裁判未提供弹速上限时使用的上限，m/s |
| `feedback_timeout_ms` | D7板间反馈有效时间，ms |
| `settle_time_ms` | 调速及恢复放行后的稳定等待时间，ms |

Keil展开 `shoot_control_state.speed`：`actual_m_s`为最近有效实测弹速，`target_m_s`为目标弹速，`limit_m_s`为采用的上限，`target_speed_rpm`为正常输出转速，`adjusted_count`为累计调整次数。`feedback_valid`检查测速有效性，`learning`检查当前学习许可，`config_valid`检查配置范围。

上电从基础转速运行，需要实际发射后才获得测速修正。调参时先观察每发弹速和轮速变化，再调整步长、余量和等待时间；弹速死区会占用部分余量。该功能依靠发射后的测速修正，首次弹速及变化过程需要实车核对。

移植时复制 `shoot_speed.[ch]`，提供配置、正常轮速上限、测速序号与时间，以及启动和堵转状态许可。算法无HAL依赖；两板方案还需同步移植D7编解码、过滤器和下板转发任务。

## 最近弹速方差

`ShootSpeed_UpdateStatistics()` 在 `shoot_speed.[ch]` 内保存最近100发有效弹速。上板按D7测速序号去重，每发更新一次；弹速小于等于零及非有限数跳过，不占窗口，也不会挤掉已有样本。统计独立于摩擦轮自适应开关和判稳许可，上电或整车软复位时清空。

采用总体方差：窗口内各弹速与均值之差的平方和除以有效发数N。未满窗口时使用已有发数；没有样本或只有一发时方差为零。满窗后每加入一发覆盖最早的有效弹速。两遍计算均值和平方偏差，只在新测速到来时执行。

| 观察变量 | 含义 |
| --- | --- |
| `shoot_control_state.speed.statistics.variance_m2_s2` | 最近有效弹速的方差，(m/s)^2；越小越集中 |
| `shoot_control_state.speed.statistics.mean_m_s` | 同一窗口的平均弹速，m/s |
| `shoot_control_state.speed.statistics.count` | 窗口内有效发数，0～100 |

统计来源是上板收到的有效主枪管测速。板间通信丢失期间的测速无法补齐。桌面上板摩擦轮JScope配置已加入方差曲线与观察项；轮速与方差单位不同，分别查看纵轴。

## 摩擦轮堵转恢复

任一轮持续低速且反馈电流较高时触发。开轮启动阶段暂不检测，左右轮分别计时，短暂掉速不会累积为堵转。触发后两轮按 `motor3508_config.left_direction/right_direction` 沿正常出弹方向给短时电流，仍使用原驱动限幅及共享群组帧，不影响升降电流槽。

脉冲及恢复观察阶段停止供弹并保持拨盘位置，随后恢复摩擦轮速度环和原供弹模式；单发中断后需要新的触发。开启期间重试次数用尽后，两轮停机、拨盘保持位置并禁止供弹，关闭摩擦轮再开启才能复位。停射或失联立即取消脉冲。未恢复的堵转可能再次触发，不能无限连续冲击。

参数在 `shoot_config.friction`：`block_speed_rpm`、`shoot_config.friction.block_current_raw`、`shoot_config.friction.block_confirm_ms` 为堵转判据；`shoot_config.friction.startup_grace_ms` 避开启动；`shoot_config.friction.boost_current_raw`、`shoot_config.friction.boost_duration_ms` 为恢复电流和时长；`shoot_config.friction.recovery_wait_ms`、`shoot_config.friction.recovery_max_attempts` 为观察时间和开启期间的重试上限。电流是 C620 原始码。脉冲时长有软件上限，实际发送失败会缩短有效脉冲，不补时。

观察 `shoot_control_state.friction.state/attempts/stuck_count`，分别表示状态、本次开启恢复次数和累计恢复次数。

## 发射阻止原因

| `upper_shoot_block_reason` | 含义 |
| --- | --- |
| `NONE` | 所需许可有效 |
| `REMOTE` | 遥控离线 |
| `LIFT` | 升降位置或安全快照未放行 |
| `REARM` | 等待物理换档或键鼠重新布防 |
| `FRICTION` | 摩擦轮离线 |
| `DIAL` | 拨盘离线，只允许待发 |

键鼠模式下 G 开启小陀螺后，F 摩擦轮锁存保留，鼠标短按单发、长按连发仍有效；升降许可、在线检测和重新布防照常生效。遥控右上档同时允许自旋与发射，供弹由拨轮决定。

升降或遥控许可恢复后需要重新布防：物理右杆重新换档，或键鼠F重新开启、重新按下鼠标左键。当前判断有优先级，显示的是首先命中的原因，清掉它后可能显示下一项。

## 接口与排查补充

`shoot_config` 管动作、堵转和时间，`shoot_heat_config` 管热量与射频；`motor3508_config`、`dial_motor_config` 管底层 PID、电流和反馈超时，见配置表。修改周期时换算以周期计数的堵转、稳定阈值。移植需保留输入边沿、统一 CAN 入口和失败重试；拨盘型号或减速比改变时重新核对一发计数和正方向。
