# 升降与安全联锁

## 文件与位置基准

`user/lift/lift_control.[ch]`；执行器为 M2006/C610，位置外层在应用中，速度 PID 在驱动中。编码器一转8192计数，`encoder_total` 是转子累计位置，不是输出轴转数。物理顶部碰顶位置为 `lift_top_contact_encoder_total`，正常高位 `lift_top_encoder_total = 机械顶点 + 下降方向×top_hold_offset_turns×每圈计数`，目标低位仍按机械顶点加下降方向×行程计算。机械零点和调头后的逻辑车头必须区分。

## 状态与动作

| 状态 | 意义 |
| --- | --- |
| `LIFT_STOPPED` | 停止或等待联锁 |
| `LIFT_CALIBRATING_UP` | 上电向上找机械顶部 |
| `LIFT_ASCENDING/DESCENDING` | 位置驱动方向；可能包含保持纠偏，不能只凭该枚举判断主动请求 |
| `LIFT_READY` | 主动动作完成，继续位置保持 |
| `LIFT_STALLED/AT_LIMIT` | 堵转或行程保护停机 |

上电校准需遥控、电机在线，Yaw 回开机机械零点并稳定，C2 请求底盘锁车后向上找顶。只有持续高电流接触才建立顶部基准，无进度本身不能完成首次校准。成功后释放 C2，首次校准仍保持碰顶位置；后续上升使用向下偏移后的正常高位，普通升降不锁底盘。

新升降边沿先进入回零等待，主动下降先要求 Pitch 抬到安全下限。从等待归中到目标到位，保存原升降目标和来源，全程保持机械归中；途中新的上升、下降方向或B按下可替换升降目标，模式键和来源切换继续忽略。到位后撤销主动请求并恢复模式操作，继续位置保持。忽略的输入已消费，到位后读取当前快照，下一次升降仍需新的拨杆或B操作；遥控失联、复位和电机故障仍可中断动作。

保持纠偏不使用无进度堵转判据，仍检查持续高电流低速。主动移动同时检查无进度和高电流低速。重复上升在已知顶部 `lift_config.calibration.top_contact_window_turns` 邻域停住可按到位处理，只有高电流接触才修正物理顶点；中途卡住仍报故障。顶部窗口内无主动下降请求时，正常偏移高位或校准碰顶保持点的反向纠偏堵转均按实测点保持，包括上升过冲后仍保留上升请求的情况；反向纠偏不重标机械顶点；主动下降和窗口外堵转仍报故障。顶部上侧的位置有效余量取到位容差与碰顶窗口的较大值，避免基准偏差先撤销许可。扩大顶部窗口会降低中途堵转区分能力。

## 五次S曲线升降

正常上升、下降从本次实测位置规划到高位、低位目标，使用与调头相同的五次位置曲线：`s(u)=10u³−15u⁴+6u⁵`，`u=t/T`。曲线两端的目标速度和加速度均为零。驱动速度指令为“曲线导数前馈＋位置误差纠偏”，单位为转子rad/s，速度PID仍在2006驱动内。

| 可调参数 | 用途 |
| --- | --- |
| `lift_config.motion.up_duration_s` | 每次上升的轨迹时间，s |
| `lift_config.motion.down_duration_s` | 每次下降的轨迹时间，s |
| `lift_config.motion.up_speed_rad_s` | 上升速度上限 |
| `lift_config.motion.down_speed_rad_s` | 下降速度上限 |
| `lift_config.hold.position_kp_rad_s_per_turn` | 轨迹位置误差的纠偏增益 |

上升、下降时间由 `LiftMotionConfig_Init()` 加载，每次动作开始时读取；途中修改时间留到下次动作。部分行程同样使用对应的整段设定时间。峰值速度为 `1.875×行程弧度/T`，若超出该方向速度上限则自动延长时间，采用值看 `lift_trajectory.duration_s`。时间是目标轨迹时长，实际到位还受负载、跟踪误差和通信重试影响。

轨迹时间结束且实测位置满足原到位容差后结束主动动作，随后保持原终点。曲线阶段不用最小启动速度；轨迹结束后若仍需追赶终点，才使用 `position_min_speed_rad_s`。首次找顶使用原来的碰顶校准速度。

中途收到新的方向或B操作时，从实测位置重新生成曲线，速度指令先归零再沿新曲线起步；换向时的实际制动受速度闭环和负载影响。Yaw/Pitch联锁暂停会撤销轨迹，恢复后重新规划；电机掉线、断控和故障停机同样撤销，恢复后保留原有的新操作要求。命令发送失败时冻结轨迹时间，长调度间隔限制单次推进。

曲线起步和收尾的计划位移可能较小，无进度检查只在该窗口要求的位移达到门槛时参与；轨迹结束后的追赶恢复原检查。高电流低速判据全程保留。时间无效或速度参数无效时取消本次动作，等待原因显示 `LIFT_WAIT_TRAJECTORY_CONFIG`。

## 安全快照逻辑

`LiftControl_SafetyUpdate` 在云台更新前运行，`LiftControl_Update` 随后执行动作。快照通过 `LiftControl_SafetyGet` 获取，超时返回false并给禁止特殊动作的结果。

| `lift_safety_state` 成员 | 条件和用途 |
| --- | --- |
| `from_top_turns` | 编码器相对碰顶基准，向下为正 |
| `position_valid` | 已校准、2006反馈有效、位置在允许行程且不是故障 |
| `upper_zone` | 顶部放行区，进入/退出使用不同门槛形成迟滞 |
| `bottom_mode_blocked` | 低位强制机械云台，并通过C1通知下板退出跟随/自旋 |
| `yaw_home_required` | 主动升降或待执行请求要求物理Yaw回零；目标到位后解除 |
| `descending` | 下降请求立即置位，持续实际下行也可置位；稳定停止后解除，顶部保持纠偏不重复锁存 |
| `special_allowed` | 遥控在线、顶部区、无主动升降及下降/回零请求、云台归中且两轴在线；惯性模式还需IMU |
| `spin_allowed` | 特殊动作许可并且IMU有效 |
| `shoot_allowed` | 特殊动作许可且不是物理升降专用档；发射仍需另行布防 |

云台以 `upper_zone` 和 `descending` 判断模式接管：顶部区外、下降、回零请求或安全位置无效时强制机械 Yaw/Pitch；通过 C1 同步限制底盘跟随和自旋。`bottom_mode_blocked` 保留低位位置迟滞，低位及下降回物理 Yaw 零点。顶部放行区继续沿用原来的进入和退出门槛。

## 参数与移植

`lift_config` 的行程、方向、速度、到位容差、顶部/低位迟滞、堵转电流速度时间及安全超时见 [配置表](10_配置与调参.md)。到位容差用于结束主动动作，不是保持死区；保持没有主动动作的最小启动速度。移植到相似升降机构需重新测行程和方向，适配2006、Yaw/Pitch对准及C2接口。缺少限位开关时首次碰顶依赖电流判断，必须验证真实反馈与机械止挡。

## 接口与排查补充

堵转快照可通过 `LiftControl_GetStallSnapshot` 读取。顶部确认窗口与正常高位向下偏移分别配置；窗口应覆盖实际碰顶偏差，过大会降低顶部邻域卡阻的区分能力。关遥控会取消动作并丢弃保持目标；出现反复联锁时先记录等待原因和快照。

| --- | --- | --- |
| `lift_control_state` | 枚举 | 动作状态；保持纠偏也会表现为上升或下降。 |
| `lift_wait_reason` | 枚举 | 当前等待或停机原因。 |
| `lift_calibrated` | bool | 顶部校准已完成。 |
| `lift_trajectory.active` | bool | 轨迹执行或等待终点到位中。 |
| `lift_trajectory.progress` | 0～1 | 当前轨迹时间进度。 |
| `lift_trajectory.duration_s` | s | 本次实际采用的轨迹时长。 |
| `lift_trajectory.elapsed_s` | s | 已成功发送的轨迹时间。 |
| `lift_trajectory.target_encoder_total` | 转子计数 | 当前曲线位置目标。 |
| `lift_trajectory.end_encoder_total` | 转子计数 | 本次曲线终点。 |
| `lift_trajectory.speed_ff_rad_s` | rad/s | 曲线导数的转子速度前馈。 |
| `lift_top_contact_encoder_total` | 转子计数 | 最近确认的机械顶部基准。 |
| `lift_top_encoder_total` | 转子计数 | 带顶部余量的正常高位目标。 |
| `lift_bottom_encoder_total` | 转子计数 | 按顶部基准和行程计算的低位目标。 |
| `lift_safety_state.from_top_turns` | 转子圈 | 距机械顶部的距离，向下为正。 |
| `lift_safety_state.position_valid` | bool | 校准、反馈与行程有效。 |
| `lift_safety_state.upper_zone` | bool | 已进入顶部特殊功能放行区。 |
| `lift_safety_state.bottom_mode_blocked` | bool | 低位联锁要求机械模式。 |
| `lift_safety_state.yaw_home_required` | bool | 本次升降请求要求 Yaw 回物理零点。 |
| `lift_safety_state.descending` | bool | 存在下降请求或确认的实际下行。 |
| `lift_safety_state.special_allowed` | bool | 允许调头等特殊动作。 |
| `lift_safety_state.spin_allowed` | bool | 允许小陀螺。 |
| `lift_safety_state.shoot_allowed` | bool | 升降侧允许发射，还需发射侧布防与热量许可。 |
| `lift_safety_state.update_ms` | ms | 安全快照生成时间。 |
| `lift_pitch_nonnegative_required` | bool | Pitch 需要抬到机械安全下限。 |

### 保持与故障快照

以下为 `user/lift/lift_control.c` 内的静态变量。堵转快照业务读取使用 `LiftControl_GetStallSnapshot()`。

| Watch 表达式 | 单位 / 类型 | 含义 |

| `lift_hold_target_encoder_total` | 转子计数 | 当前执行的升降或保持目标。 |
| `lift_hold_target_valid` | bool | 保持目标已经锁定。 |
| `stall_snapshot.valid` | bool | 已记录过堵转快照。 |

| `stall_snapshot.requested_direction` | 枚举 | 堵转瞬间的主动请求。 |
| `stall_snapshot.target_encoder_total` | 转子计数 | 堵转瞬间的位置目标。 |
