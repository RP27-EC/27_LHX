# 上板电机驱动

## 总线和职责

| 文件 | 设备 | 控制/反馈 |
| --- | --- | --- |
| `bottom_driven/motor/motor4310/motor4310.*` | Yaw/Pitch 4310 MIT | Pitch CAN1，Yaw CAN2；ID见配置 |
| `bottom_driven/motor/motor3508/motor3508.*` | 双摩擦轮3508/C620 | CAN1反馈0x201/0x202，群组0x200前两槽 |
| `bottom_driven/motor/motor2006/motor2006.*` | 升降2006/C610 | CAN1反馈0x204，群组0x200第4槽 |
| `bottom_driven/motor/dial_motor/dial_motor.*` | LK4005拨盘 | CAN1命令/反馈0x141，0xA1电流指令 |

驱动负责协议换算、累计编码器、在线判断、闭环和发送。应用负责模式、安全、动作目标。3508摩擦轮与2006共享0x200，实际帧由2006模块保存各槽并统一拼接；禁止两个驱动分别发送其余槽全零的帧。

## 数据和单位

- `motor4310_data[]`：MIT位置、速度、转矩和累计角度；`motor4310_position_pids[]/speed_pids[]` 是驱动闭环。开机归中和机械保持的Yaw共用应用层陀螺仪速度环，独立调头使用驱动编码器串级闭环。
- `motor3508_feedback[]` 与 `motor3508_speed_pid[]`：摩擦轮反馈、速度PID；转速使用转子rpm。
- `motor2006_feedback` 与 `motor2006_speed_pid`：累计编码器计数、转子rpm、原始电流。升降接口目标速度为rad/s，驱动把rpm转rad/s。
- `dial_motor_feedback`：4005累计角度等；`dial_motor_position_pid/speed_pid/continuous_speed_pid`：单发位置/速度及独立连发速度环。

MIT原始转矩码、DJI原始电流码和物理N·m/A不是同一单位。换算常量与限幅在 `peripheral_config`，应用不能把原始码直接当物理量。

## 在线、停机与失败

摩擦轮提供两个停机接口：`Motor3508_Stop()` 清空速度环并发送零电流；`Motor3508_BrakeStop()` 按新鲜轮速反馈执行目标零速的比例闭环，近零速或反馈离线时撤掉电流。保险和遥控断控使用主动停轮，堵转故障停止使用零电流接口。参数集中在 `motor3508_config.brake`，状态在 `motor3508_brake_state`，模块入口为 `motor3508.brake_stop()` 与 `motor3508.control.brake`。

成功发送只表示CAN邮箱入队。反馈时间戳决定在线；心跳/命令超时用于停止旧输出。`Motor4310_AllOnline`、各驱动在线函数用于许可判断；失败返回值应保留给动作状态机，不能默认电机已执行。反馈建议通过Get接口读取一致快照。

## 移植顺序

适用于相同电机协议的HAL工程：配置CAN时钟/引脚/滤波/FIFO → 配置ID、方向与限幅 → 添加驱动和PID → 初始化 → 统一接收回调分发 → 周期心跳与控制。HAL回调只能有一个实际定义，多模块由它分发。4310需分别核对两轴总线，DJI群组必须指定唯一拼帧者，4005需保留收发间隔限制。参数详见 [配置表](10_配置与调参.md)。

## 常用观察变量

### 4310 云台电机

下标 `MOTOR4310_PITCH=0`、`MOTOR4310_YAW=1`。单圈位置范围由 MIT 协议映射，原始速度和转矩分别使用协议码。

| Watch 表达式 | 单位 / 类型 | 含义 |
| --- | --- | --- |
| `motor4310_data[MOTOR4310_YAW].total_angle` | 累计计数 | Yaw 电机累计位置。 |
| `motor4310_data[MOTOR4310_PITCH].total_angle` | 累计计数 | Pitch 电机累计位置。 |
| `motor4310_data[MOTOR4310_YAW].angle` | 单圈码 | Yaw 单圈编码器原值。 |
| `motor4310_data[MOTOR4310_YAW].speed` | MIT 速度码 | Yaw 电机速度反馈；机械 Yaw 内环实际采用 IMU。 |
| `motor4310_data[MOTOR4310_PITCH].speed` | MIT 速度码 | 机械 Pitch 速度内环的电机反馈。 |
| `motor4310_data[MOTOR4310_YAW].online` | bool | Yaw 心跳检查的在线状态；Pitch 可替换数组下标查看。 |
| `motor4310_data[MOTOR4310_YAW].enabled` | bool | 最近成功入队的使能或失能命令状态。 |
| `motor4310_data[MOTOR4310_YAW].rx_count` | 帧 | Yaw 有效反馈累计次数。 |
| `motor4310_position_pids[MOTOR4310_YAW].Output` | 速度码 | 机械 Yaw 位置环输出，随后转换为 deg/s。 |
| `motor4310_speed_pids[MOTOR4310_PITCH].Output` | MIT 转矩码 | Pitch 驱动速度环输出，随后叠加重力补偿。 |

### 3508 摩擦轮

摩擦轮数组有效下标为 0、1，对应电机 ID 1、2。

| Watch 表达式 | 单位 / 类型 | 含义 |
| --- | --- | --- |
| `motor3508_feedback[0].speed_rpm` | 转子 rpm | 左摩擦轮实际转速；[1] 为右轮，两轮正常转向相反。 |
| `motor3508_feedback[0].current_raw` | C620 电流码 | 左摩擦轮实际力矩电流反馈。 |
| `motor3508_feedback[0].online` | bool | 左摩擦轮在线状态。 |
| `motor3508_feedback[0].rx_count` | 帧 | 左摩擦轮有效反馈次数。 |
| `motor3508_speed_pid[0].SetPoint` | 转子 rpm | 左摩擦轮速度 PID 目标。 |
| `motor3508_speed_pid[0].Output` | C620 电流码 | 左摩擦轮速度 PID 输出。 |
| `motor3508_brake_state.feedback_valid[0]` | bool | 左轮本周期停轮反馈有效。 |
| `motor3508_brake_state.active[0]` | bool | 左轮本周期正在主动制动。 |
| `motor3508_brake_state.current_raw[0]` | C620 电流码 | 左轮本周期制动电流命令。 |

### 2006 升降电机

速度环目标使用 rad/s，原始转速反馈使用 rpm。驱动计算时完成单位转换。

| Watch 表达式 | 单位 / 类型 | 含义 |
| --- | --- | --- |
| `motor2006_feedback.encoder_total` | 转子计数 | 升降电机相对首帧累计位置。 |
| `motor2006_feedback.speed_rpm` | 转子 rpm | 升降电机实际转速。 |
| `motor2006_feedback.current_raw` | C610 电流码 | 升降电机实际电流反馈。 |
| `motor2006_feedback.online` | bool | 升降电机心跳在线状态。 |
| `motor2006_feedback.rx_count` | 帧 | 升降电机有效反馈次数。 |
| `motor2006_speed_pid.SetPoint` | 转子 rad/s | 升降速度环目标。 |
| `motor2006_speed_pid.Output` | C610 电流码 | 升降速度环输出。 |

| Watch 表达式 | 单位 / 类型 | 含义 |

| `dial_motor_feedback.speed_dps` | deg/s | 拨盘实际角速度。 |
| `dial_motor_feedback.current_raw` | 电流码 | 拨盘实际转矩电流反馈。 |
| `dial_motor_feedback.online` | bool | 拨盘心跳在线状态。 |
| `dial_motor_position_pid.Error` | 累计计数 | 拨盘位置目标减实际位置。 |
| `dial_motor_speed_pid.Output` | 电流码 | 拨盘单发或保持速度环输出。 |
| `dial_motor_continuous_speed_pid.Output` | 电流码 | 拨盘连发独立速度环输出。 |
| `dial_motor_tx_diagnostics.last_current_raw` | 电流码 | 最近成功入队的 A1 电流命令。 |
| `dial_motor_tx_diagnostics.queued_count` | 帧 | 拨盘命令成功入队次数。 |
| `dial_motor_tx_diagnostics.guard_busy_count` | 次 | 发送间隔未满足而跳过的次数。 |
| `dial_motor_tx_diagnostics.mailbox_busy_count` | 次 | CAN 发送邮箱全满次数。 |
| `dial_motor_tx_diagnostics.send_error_count` | 次 | HAL 发送失败次数。 |
