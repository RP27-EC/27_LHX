# 云台与调头

## 文件和控制入口

`user/gimbal/cloud_terrace.[ch]`，周期调用 `CloudTerrace_Update`。输入为遥控快照、升降安全状态、4310 编码器、上板 IMU 与下板 D4 角速度；输出为两轴电机命令和 C1 状态。开机机械归中先于正常控制，任一轴离线重新退出归中状态。

## Yaw 控制

| 场景 | 位置目标 | 速度反馈与输出 |
| --- | --- | --- |
| 开机归中、机械保持或升降回零 | 编码器相对开机零点的车头/车尾目标；开机和升降回零强制物理正方向 | 位置 PID 输出速度码，换算成 deg/s；上板 IMU 速度内环输出转矩码 |
| 跟随或小陀螺云台控制 | 摇杆/鼠标积分形成惯性累计航向目标 | IMU 角度外环 + IMU 角速度内环 |
| 独立调头 | 从当前位置到最近反向车头的五次轨迹 | 原驱动编码器串级闭环，独立 `motor4310_config.yaw_turn` 参数 |

机械保持只用一套位置 PID。连续软死区扣除死区宽度，死区内取消位置纠偏速度，但速度环仍工作。回正速度按剩余误差平方根减小，参数 `cloud_config.yaw.mechanical.brake_speed_at_1deg_raw`；零关闭该额外限制。

升降位于顶部放行区外、处于下降或回零阶段、位置及安全快照无效时，两轴强制机械控制：Yaw 使用编码器位置与陀螺仪速度闭环，Pitch 使用编码器位控。低位和下降阶段 Yaw 回物理正方向；中间高度保持沿用机械模式的最近车头目标。顶部区内且下降联锁解除后，恢复遥控请求的云台模式。C1 的机械联锁位同时通知下板退出跟随和自旋。

机械 Yaw 每周期按单圈相对角选择车头或车尾，门槛沿用 `cloud_config.yaw.front_switch_deg`。目标取离当前累计编码器位置最近的等效角，绕过多圈后也只回最近的一圈。开机和升降回零强制选择物理车头，同样按最近一圈回正；开机机械零点保持不变。切换车头或等效圈数时复位闭环，目标不变时保留 PID 状态。

开机 Yaw 归中直接调用机械保持控制函数，位置环共用 `motor4310_config.yaw_hold.position`，陀螺仪内环、软死区、回正限速和底盘前馈共用 `cloud_config.yaw.mechanical`。Pitch 归中与机械模式共用 `motor4310_config.pitch` 和 `cloud_config.pitch.gravity_k`。`cloud_config.home` 只配置归中完成的误差、反馈速度和连续稳定周期；归中期间 IMU 无效或任一轴命令入队失败会清除稳定计数，恢复后继续回零。归中完成后机械 Yaw 沿用现有目标和 PID 状态。

机械模式：`速度目标 = 位置环速度码 × command_deg_s_per_raw + chassis_rate_ff_gain × 底盘角速度`。前馈经过独立限幅；D4 超时/无效立即归零。速度环根据合成目标产生转矩。增益正负应按两板 IMU 安装方向确认。前馈在机械控制分支使用，包括开机归中和升降强制机械回零；惯性控制及独立调头不使用。

## Pitch 控制

机械模式摇杆积分改变编码器目标，驱动做位置—速度串级控制。跟随/小陀螺使用 IMU Pitch 角外环与投影角速度内环：`(cos(roll)×gyro_y − sin(roll)×gyro_z)×rad_to_deg×方向`。保留编码器机械上下限、目标领先限制与升降安全下限。两种模式均保留 `pitch_gravity_k × cos(相对机械归中角)` 重力补偿。模式变化与 IMU 恢复从当前姿态接管，避免沿用旧角度。

## 调头五次曲线

以 `cloud_config.yaw.turn.duration_s` 为目标轨迹时间，`u=累计有效时间/T`，范围0～1；进度为 `10u³−15u⁴+6u⁵`，位置为 `起点 + 位移×进度`。首尾速度和加速度为零。发送失败不推进有效轨迹时间，轨迹结束后仍须满足角误差、速度和连续稳定周期才完成，所以实际动作时间可能大于T。升降回零、许可失效、离线会取消调头。调头期间 C1 通知下板停车。

## 接口与排查补充

参数在 `cloud_config` 和 `motor4310_config`，见 [完整配置表](10_配置与调参.md)。先核对反馈方向和单位，再调内环、外环、回正限幅与前馈。模块依赖两轴驱动、遥控、升降及通信；移植时整组接入或替换这些接口。

## 常用观察变量

### 全局状态与控制输出

画曲线时先选目标、反馈和转矩。机械误差在机械分支更新；Pitch 的惯性观察量在惯性分支更新，机械 Pitch 看下方编码器目标。

| Watch 表达式 | 单位 / 类型 | 含义 |
| --- | --- | --- |
| `cloud_terrace_home_state` | 枚举 | 0 等待归中，1 正在归中，2 归中完成。 |
| `cloud_front_reversed` | bool | 当前逻辑车头朝向物理车尾。 |
| `cloud_yaw_mechanical_error_deg` | deg | 机械 Yaw 目标减编码器实际位置，仅机械控制分支更新。 |
| `cloud_yaw_mechanical_speed_limit_raw` | 速度码 | 按剩余误差计算的回正速度上限。 |
| `cloud_yaw_mechanical_gyro_online` | bool | 机械 Yaw 控制本周期取得有效 IMU。 |
| `cloud_yaw_imu_online` | bool | 惯性 Yaw 闭环已接管有效 IMU。 |
| `cloud_yaw_target_deg` | deg | 惯性 Yaw 累计角度目标。 |
| `cloud_yaw_angle_deg` | deg | 惯性 Yaw 闭环使用的实际累计角度。 |
| `cloud_yaw_rate_target_deg_s` | deg/s | Yaw 速度内环目标，机械模式包含底盘前馈。 |
| `cloud_yaw_rate_deg_s` | deg/s | Yaw 速度内环使用的实际角速度。 |
| `cloud_yaw_torque_raw` | MIT 转矩码 | Yaw 本周期计算的转矩指令；入队结果由控制路径处理。 |
| `cloud_yaw_chassis_rate_online` | bool | 底盘 D4 角速度反馈本周期有效。 |
| `cloud_yaw_chassis_rate_deg_s` | deg/s | 底盘反馈的角速度。 |
| `cloud_yaw_chassis_rate_ff_deg_s` | deg/s | 经过增益与限幅后的底盘角速度前馈。 |
| `cloud_pitch_imu_online` | bool | Pitch 惯性闭环使用有效 IMU。 |
| `cloud_pitch_target_deg` | deg | Pitch 惯性角度目标，仅惯性分支更新。 |
| `cloud_pitch_angle_deg` | deg | Pitch 惯性闭环使用的实际角度。 |
| `cloud_pitch_rate_target_deg_s` | deg/s | Pitch 惯性速度内环目标。 |
| `cloud_pitch_rate_deg_s` | deg/s | Pitch 投影角速度经过低通后的反馈。 |
| `cloud_pitch_torque_raw` | MIT 转矩码 | Pitch 惯性控制叠加重力补偿并限幅后的指令。 |
| `cloud_turnaround_active` | bool | 独立调头正在执行。 |
| `cloud_turn_progress` | 0～1 | 本次调头已成功推进的时间进度。 |
| `cloud_turn_duration_s` | s | 调头开始时锁定的轨迹时长。 |
| `cloud_turn_target_deg` | deg | 当前轨迹位置目标，相对开机机械零点。 |
