# 下板板间通信与底盘总线

## 总线分工

`communication.[ch]` 管FDCAN2板间帧，`chassis_can.[ch]` 管FDCAN1四轮、超电与无线充，均在 `bottom_driven/communication`。统一HAL FIFO0回调分发到对应模块。H7双FDCAN共用Message RAM，CubeMX重新生成时需核对两块区域不重叠。

## 两板协议

板间总线是上板CAN2与下板FDCAN2，标准11位ID、经典CAN、8字节，小端字段。电机DJI群组指令使用大端，不能把两种协议的字节序混用。

| ID | 方向 | 数据与含义 |
| --- | --- | --- |
| D1/D2/D3 | 下→上 | 原始DBUS第0～7、8～15、16～17字节；D3余位补零，上板按顺序拼帧 |
| D4 | 下→上 | 字节0～1有符号int16，乘0.01得deg/s；字节2 bit0有效 |
| D5 | 下→上 | 四个小端int16，四轮转子rpm |
| D6 | 下→上 | 字节0～1当前热量、2～3热量上限、4～5每秒冷却量，均uint16小端；字节6 bit0数据有效、bit1发射电源许可；字节7热量更新序号 |
| D7 | 下→上 | 字节0～1实测弹速、2～3弹速上限，uint16×0.01m/s；字节4～5测速序号，uint16小端；字节6 bit0测速有效、bit1上限有效；字节7样本年龄，向上取整为10ms单位 |
| C1 | 上→下 | 字节0～1为机械相对Yaw角，int16×0.01°；字节2为状态位 |
| C2 | 上→下 | 字节0标识0xA6，字节1 bit0校准锁车，字节2请求序号 |

C1字节2：bit0角有效、bit1调头中、bit2允许调头、bit3允许自旋、bit4上板选中小陀螺、bit5升降强制机械模式，包含顶部区外、下降、回零和无效安全位置。bit5沿用现有位置，下板收到后退出跟随及自旋。模式位与角度有效位独立，不能仅凭角有效就自旋。C2只用于升降校准，普通升降不锁车。各种状态分别检查超时，不应把最后值永久当作有效值。

D4在下板底盘任务持续发送，包括机械模式与停车状态；无效时明确发无效位。上板机械Yaw读取D4作速度目标前馈，D5目前主要是轮速接口与观察，不能据此认定已实现防打滑。

D6由下板裁判任务按 `remote_config.heat_tx_period_ms` 转发。机器人状态和热量消息都新鲜时才置有效位，重复转发保持热量序号不变。上板通过 `Communication_GetHeatSnapshot()` 读取，再按 `shoot_heat_config.referee_timeout_ms` 检查板间帧超时。CAN2 bank 16同时放行D5/D6/D7，bank 15保留给Yaw电机，修改协议后两板同步烧录。

D7按 `remote_config.shot_tx_period_ms` 转发主17mm枪管测速。测速和弹速上限分别置有效位；重复转发保持测速序号，更新原样本年龄。上板通过 `Communication_GetShotSnapshot()` 读取并恢复本板时间域中的测速时刻，再由发射模块检查D7超时、测速年龄、启动和调速稳定时间。新增D7无需修改外设引脚。

## 参数和移植

`communication_config` 指定角度、模式、角速度、锁车有效期及通信设置，具体字段见配置表。移植需配置物理总线、标准帧过滤、FIFO中断和唯一回调，调用Init，周期服务，统一单位/字节序/有效位。改变协议或ID应同时修改两板、过滤器、超时以及文档。不要用阻塞等待代替发送失败处理。

## 接口与排查补充

通信任务调用 `Communication_Service`，Bus-Off 后限频 Stop/Start 恢复。C1、C2 通过 Get 接口检查超时；C2 可同时返回请求序号。`ChassisCan_Send` 是电机和超电控制帧的统一发送入口，各设备共用滤波和接收分发。

## 常用观察变量

`board_link.data.c1`、`c2` 是指向原始帧的指针，成员使用 `->`。语义和超时判断由对应快照接口完成，位图定义见本页协议表。

| Watch 表达式 | 单位 / 类型 | 含义 |
| --- | --- | --- |
| `communication_rx_count` | 帧 | 板间 C1/C2 接收累计次数。 |
| `communication_last_rx_id` | CAN ID | 最近板间接收的标准 ID。 |
| `communication_bus_off_count` | 次 | 板间总线 Bus-Off 恢复尝试次数。 |
| `communication_restart_count` | 次 | 板间总线恢复启动成功次数。 |
| `board_link.data.c1->rx_count` | 帧 | C1 云台角度与许可帧接收次数。 |
| `board_link.data.c1->last_rx_ms` | ms | 最近 C1 接收时间。 |
| `board_link.data.c1->data[2]` | 位图 | C1 调头、自旋、角度有效和升降机械联锁标志。 |
| `board_link.data.c2->rx_count` | 帧 | C2 升降校准锁车帧接收次数。 |
| `board_link.data.c2->data[1]` | 0/1 | C2 请求锁车标志，使用前还需检查帧魔数和时效。 |
| `chassis_can_state.rx_count` | 帧 | FDCAN1 有效数据帧接收累计数。 |
| `chassis_can_state.rx_error_count` | 次 | FDCAN1 取帧或格式检查错误数。 |
| `chassis_can_state.tx_count` | 帧 | FDCAN1 发送成功入队累计数。 |
| `chassis_can_state.tx_error_count` | 次 | FDCAN1 发送入队失败数。 |
| `chassis_can_state.last_rx_id` | CAN ID | FDCAN1 最近接收 ID。 |
| `chassis_can_state.last_tx_id` | CAN ID | FDCAN1 最近成功发送 ID。 |

完整速查与观察方法见 [本板观察变量速查](00_观察变量速查.md)。
