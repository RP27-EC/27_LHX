# 超级电容与无线充

## 文件与总线

`bottom_driven/communication/power/power_communication.[ch]`。FDCAN1统一模块chassis_can配置过滤器和分发，与四轮电机共总线。PowerCommunication_Init清状态，Service更新在线并周期发控制帧；GetSnapshot提供一致状态。

## 协议与换算

| ID | 内容 |
| --- | --- |
| 0x211 | 电容状态：0～1底盘功率int16，2～3电容电压int16，4～5电容电流int16，6标志 |
| 0x212 | 无线充功率与充电状态 |
| 0x222 | 下板发送的基础电容控制帧 |

电容电压 `V=(raw+32000)×25/64000`，电容电流 `A=raw×16/32000`；多字节小端。0x211功率按本机已确认原值直接为W，负值保留。字节6 bit0允许放电，bit1预充中。当前协议来自模板与实物确认，不能推广到其他厂家超电而不核对。

0x222底盘上限取ChassisPower_GetLimit的裁判/备用策略；裁判明确关闭输出则基础使能关闭。字节0发送裁判0x0202的实时缓冲能量，单位J，每次发送通过裁判快照接口重新读取。未收到有效数据或数据过期时发送0；数值超过超电接收端范围时饱和到250，避免单字节截断。有效期沿用REFEREE_OFFLINE_TIMEOUT_MS，发送周期由power_communication_config.tx_period_ms设置。

超电上车控制分支会根据收到的缓冲能量调整输入功率目标。裁判缓冲为满值且Turbo关闭时，缓冲环修正为零；缓冲减少时，输入功率目标随之降低。当前不在下板积分计算缓冲能量。

## 排查和移植

先看0x211接收次数，再看在线时间与原始字段；不要把电容端电压与力矩电流乘积当真实功率。0x222错误计数增长检查FDCAN邮箱和发送频率，避免阻塞底盘任务。移植需保留统一CAN入口，重新核协议ID、换算、标志位、测量位置、超时与是否允许回馈。无无线充硬件时online为false属于正常现象。

## 常用观察变量

核对缓冲发送时同时看裁判缓冲、0x0202 新鲜度与 `control.raw[0]`。控制帧记录的是成功入队的数据；电容端电压电流与底盘输出功率分别观察。

| Watch 表达式 | 单位 / 类型 | 含义 |
| --- | --- | --- |
| `power_communication_state.capacitor.chassis_power_raw` | W | 本机超电上报的底盘输出功率；当前协议原值直接采用。 |
| `power_communication_state.capacitor.voltage_v` | V | 换算后的电容端电压。 |
| `power_communication_state.capacitor.current_a` | A | 换算后的电容端电流，保留协议正负方向。 |
| `power_communication_state.capacitor.voltage_raw` | 原始码 | 电容电压原值。 |
| `power_communication_state.capacitor.current_raw` | 原始码 | 电容电流原值。 |
| `power_communication_state.capacitor.discharge_available` | bool | 设备反馈当前允许放电。 |
| `power_communication_state.capacitor.precharge_active` | bool | 设备反馈当前正在预充。 |
| `power_communication_state.capacitor.online` | bool | 超电状态帧尚未超时。 |
| `power_communication_state.capacitor.rx_count` | 帧 | 0x211 接收次数。 |
| `power_communication_state.capacitor.last_rx_ms` | ms | 最近 0x211 接收时间。 |
| `power_communication_state.control.raw[0]` | J | 最近成功入队的缓冲能量字节。 |
| `power_communication_state.control.raw[7]` | 位图 | 最近成功入队的基础使能、Turbo、预充标志。 |
| `power_communication_state.control.tx_count` | 帧 | 0x222 成功入队次数。 |
| `power_communication_state.control.tx_error_count` | 次 | 0x222 入队失败次数。 |
| `power_communication_config.cap_enabled` | bool | 配置中的超电基础开关。 |
| `power_communication_config.turbo_enabled` | bool | 配置中的 Turbo 开关。 |
| `power_communication_state.wireless.charging_power_w` | W | 无线充反馈的充电功率换算值。 |
| `power_communication_state.wireless.charging` | bool | 无线充反馈正在充电。 |
| `power_communication_state.wireless.online` | bool | 无线充状态帧尚未超时。 |

完整速查与观察方法见 [本板观察变量速查](00_观察变量速查.md)。
