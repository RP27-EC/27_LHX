# 超级电容与无线充

## 文件与总线

`bottom_driven/communication/power_communication.[ch]`。FDCAN1统一模块chassis_can配置过滤器和分发，与四轮电机共总线。PowerCommunication_Init清状态，Service更新在线并周期发控制帧；GetSnapshot提供一致状态。

## 协议与换算

| ID | 内容 |
| --- | --- |
| 0x211 | 电容状态：0～1底盘功率int16，2～3电容电压int16，4～5电容电流int16，6标志 |
| 0x212 | 无线充功率与充电状态 |
| 0x222 | 下板发送的基础电容控制帧 |

电容电压 `V=(raw+32000)×25/64000`，电容电流 `A=raw×16/32000`；多字节小端。0x211功率按本机已确认原值直接为W，负值保留。字节6 bit0允许放电，bit1预充中。当前协议来自模板与实物确认，不能推广到其他厂家超电而不核对。

0x222底盘上限取ChassisPower_GetLimit的裁判/备用策略；裁判明确关闭输出则基础使能关闭。充放电其他字段、周期在power_communication_config，当前缓冲字段为配置值，不是软件缓冲能量算法。

## 变量

`power_communication_state.capacitor`：chassis_power_raw、voltage_raw/current_raw与voltage_v/current_a、discharge_available/precharge_active、raw、last_rx_ms/rx_count/received/online。online表示最近收帧，不保证电容可放电。

`wireless`：charging_power_raw/charging_power_w、charging和online，在线不等于正在充电。`control.raw/last_tx_ms/tx_count/tx_error_count` 是最近成功入队控制帧与统计。

## 排查和移植

先看0x211接收次数，再看在线时间与原始字段；不要把电容端电压与力矩电流乘积当真实功率。0x222错误计数增长检查FDCAN邮箱和发送频率，避免阻塞底盘任务。移植需保留统一CAN入口，重新核协议ID、换算、标志位、测量位置、超时与是否允许回馈。无无线充硬件时online为false属于正常现象。
