## 观察方法

- 表格中的完整表达式可逐项加入 Keil Watch；数组示例使用有效下标，其他元素按本页说明替换。
- 两板分别加载对应 AXF。重新编译后更新调试符号；JScope 等按地址采样的工具需重新载入 ELF。
- 确认程序运行且调试器启用了运行时刷新。曲线观察用 JScope 或支持采样的内存工具，采样周期按要观察的动作选择。
- 单位区分转子 rpm、rad/s、deg/s、累计编码器计数和电流原始码。目标、指令与实际反馈分别记录。
- 数据时效同时查看在线、新鲜度、接收计数和时间戳。裁判结构保留最后有效值，过期后仍能看到旧数值。
- 文件内 `static` 变量在对应源文件作用域查看。找不到表达式时通过调试器 Symbols 定位；编译优化可能影响内部变量可见性。
- Watch 用于观察；应用读取多成员状态继续使用快照接口。

## 常见问题排查

| 现象 | 建议观察顺序 |
| --- | --- |
| 开机不归中 | `communication_rc_online` → `motor4310_data[0].online`、`motor4310_data[1].online` → `gimbal_imu.online` → `cloud_terrace_home_state` |
| 机械 Yaw 保持或回正异常 | `cloud_yaw_mechanical_error_deg` → `cloud_yaw_rate_target_deg_s`、`cloud_yaw_rate_deg_s` → `cloud_yaw_torque_raw` → `cloud_yaw_chassis_rate_ff_deg_s` |
| 调头慢或停在中途 | `cloud_turnaround_active` → `cloud_turn_progress`、`cloud_turn_target_deg` → Yaw 编码器与速度反馈 |
| 升降后功能未放行 | `lift_wait_reason` → `lift_safety_state.position_valid` → `lift_safety_state.upper_zone` → `lift_safety_state.yaw_home_required`、`lift_safety_state.descending` |
| 无法供弹 | `upper_shoot_block_reason` → `lift_safety_state.shoot_allowed` → `shoot_heat_state.referee_valid`、`shoot_heat_state.output_allowed` → `shoot_heat_state.remaining` |
| 热量变化但射频未变化 | `shoot_heat_state.calibration_count` → `shoot_heat_state.predicted_heat`、`shoot_heat_state.referee_heat` → `shoot_heat_state.continuous_rate_hz` |
| 摩擦轮弹速不调整 | `shoot_control_state.speed.feedback_valid` → `shoot_control_state.speed.learning` → `shoot_control_state.speed.actual_m_s`、`shoot_control_state.speed.target_m_s` → `shoot_control_state.speed.adjusted_count` |
| 拨盘不保持或动作断续 | `dial_motor_feedback.online` → `shoot_control_state.dial.target`、`dial_motor_feedback.encoder_total` → `dial_motor_tx_diagnostics.mailbox_busy_count` |
