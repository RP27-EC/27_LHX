## 遥控阈值表

默认值在本板 `config/application_config.c` 的 `InputControlConfig_Init()` 中修改；运行时可将完整成员路径加入 Keil Watch 调整。两板的 `input_control_config` 保持一致。

| Watch 表达式 | 类型 / 单位 | 调整作用与触发条件 |
| --- | --- | --- |
| `input_control_config.wheel.trigger_raw` | int16 / 原始通道值 | 下拨发射与复位门槛；原始拨轮小于其负值时触发。 |
| `input_control_config.wheel.rearm_raw` | int16 / 原始通道值 | 原始拨轮回到其负值及以上时，允许下次下拨。 |
| `input_control_config.wheel.continuous_ms` | uint32 / ms | 下拨发射持续超过此时间后转连发。 |
| `input_control_config.reset_hold_ms` | uint32 / ms | 遥控、键盘复位组合连续保持超过此时间后触发。 |
| `input_control_config.takeover_raw` | int16 / 原始通道值 | 当前或基准摇杆、拨轮幅值达到门槛，同时满足变化条件才接管遥控。 |
| `input_control_config.change_raw` | int16 / 原始通道值 | 相对最近有效操作基准的变化量达到门槛才判新操作；缓慢拨动可累计。 |
| `input_control_config.mouse_raw` | int16 / 鼠标原始位移 | X或Y单次位移绝对值超过此值时接管键鼠；鼠标按钮的新变化同样可接管。 |
| `cloud_config.yaw.turn.wheel_trigger_raw` | int32 / 原始通道值 | 上拨调头门槛；原始拨轮严格大于此值才触发。 |
| `cloud_config.yaw.turn.wheel_rearm_raw` | int32 / 原始通道值 | 原始拨轮回到此值及以下时，允许下次上拨调头。 |
| `shoot_config.mouse_continuous_threshold_ms` | uint32 / ms | 左键持续按下超过此时间后转连发。 |

调头参数由 `YawTurnConfig_Init()` 加载；鼠标连发门槛由 `ShootConfig_Init()` 加载。

触发幅值使用正数，回中幅值小于触发幅值，触发幅值小于遥控有效满量程。上板 `cloud_config.yaw.turn` 与下板 `chassis_config.turn` 的拨轮阈值同步调整。参数只改变门槛，升降、保险和失联联锁仍参与判断。

## 惯性Yaw松杆回正

| Watch表达式 | 含义 |
| --- | --- |
| `cloud_config.yaw.follow_center.enabled` | 开启有效Yaw操作后、越过换头门槛的松杆回正 |
| `cloud_config.yaw.follow_center.tolerance_deg` | 完成角度误差，deg；需大于机械软死区 |
| `cloud_config.yaw.follow_center.speed_raw_max` | 完成时允许的电机相对速度码幅值 |
| `cloud_config.yaw.follow_center.stable_cycles` | 位置、速度及发送连续合格周期数 |
| `cloud_config.yaw.front_switch_deg` | Yaw最近车头切换门槛；底盘车头门槛在下板单独配置 |
| `cloud_yaw_follow_center.phase` | 0无手动请求、1回正、2本次完成后保持惯性、3手动输入中 |
| `cloud_yaw_follow_center.target_counts` | 当前最近车头的累计编码器目标 |

配置初始化见 `config/application_config.c` 的 `YawFollowCenterConfig_Init()`；回正速度与力矩共用机械Yaw参数，流程见 [云台模块](03_云台与调头.md#惯性跟随松杆回正)。

## 观察方法

- 表格中的完整表达式可逐项加入 Keil Watch；数组示例使用有效下标，其他元素按本页说明替换。
- 两板分别加载对应 AXF。重新编译后更新调试符号；JScope 等按地址采样的工具需重新载入 ELF。
- 确认程序运行且调试器启用了运行时刷新。曲线观察用 JScope 或支持采样的内存工具，采样周期按要观察的动作选择。
- 单位区分转子 rpm、rad/s、deg/s、累计编码器计数和电流原始码。目标、指令与实际反馈分别记录。
- 数据时效同时查看在线、新鲜度、接收计数和时间戳。裁判结构保留最后有效值，过期后仍能看到旧数值。
- 文件内 `static` 变量在对应源文件作用域查看。找不到表达式时通过调试器 Symbols 定位；编译优化可能影响内部变量可见性。
- Watch 用于观察；应用读取多成员状态继续使用快照接口。

## 常见问题排查

| 现象 | 建议观察顺序 |
| --- | --- |
| 开机不归中 | `communication_rc_online` → `motor4310_data[0].online`、`motor4310_data[1].online` → `gimbal_imu.online` → `cloud_terrace_home_state` |
| 机械 Yaw 保持或回正异常 | `cloud_yaw_mechanical_error_deg` → `cloud_yaw_rate_target_deg_s`、`cloud_yaw_rate_deg_s` → `cloud_yaw_torque_raw` → `cloud_yaw_chassis_rate_ff_deg_s` |
| 调头慢或停在中途 | `cloud_turnaround_active` → `cloud_turn_progress`、`cloud_turn_target_deg` → Yaw 编码器与速度反馈 |
| 升降后功能未放行 | `lift_wait_reason` → `lift_safety_state.position_valid` → `lift_safety_state.upper_zone` → `lift_safety_state.yaw_home_required`、`lift_safety_state.descending` |
| 无法供弹 | `upper_shoot_block_reason` → `lift_safety_state.shoot_allowed` → `shoot_heat_state.referee_valid`、`shoot_heat_state.output_allowed` → `shoot_heat_state.remaining` |
| 热量变化但射频未变化 | `shoot_heat_state.calibration_count` → `shoot_heat_state.predicted_heat`、`shoot_heat_state.referee_heat` → `shoot_heat_state.continuous_rate_hz` |
| 摩擦轮弹速不调整 | `shoot_control_state.speed.feedback_valid` → `shoot_control_state.speed.learning` → `shoot_control_state.speed.actual_m_s`、`shoot_control_state.speed.target_m_s` → `shoot_control_state.speed.adjusted_count` |
| 拨盘不保持或动作断续 | `dial_motor_feedback.online` → `shoot_control_state.dial.target`、`dial_motor_feedback.encoder_total` → `dial_motor_tx_diagnostics.mailbox_busy_count` |
