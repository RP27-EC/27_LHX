## 遥控阈值表

默认值在本板 `config/application_config.c` 的 `InputControlConfig_Init()` 中修改；运行时可将完整成员路径加入 Keil Watch 调整。两板的 `input_control_config` 保持一致。

| Watch 表达式 | 类型 / 单位 | 调整作用与触发条件 |
| --- | --- | --- |
| `input_control_config.wheel.trigger_raw` | int16 / 原始通道值 | 下拨发射与复位门槛；原始拨轮小于其负值时触发。 |
| `input_control_config.wheel.rearm_raw` | int16 / 原始通道值 | 原始拨轮回到其负值及以上时，允许下次下拨。 |
| `input_control_config.wheel.continuous_ms` | uint32 / ms | 下拨发射持续超过此时间后转连发。 |
| `input_control_config.reset_hold_ms` | uint32 / ms | 遥控、键盘复位组合连续保持超过此时间后触发。 |
| `input_control_config.takeover_raw` | int16 / 原始通道值 | 当前或基准摇杆、拨轮幅值达到门槛，同时满足变化条件才接管遥控。 |
| `input_control_config.change_raw` | int16 / 原始通道值 | 相对最近有效操作基准的变化量达到门槛才判新操作；缓慢拨动可累计。 |
| `input_control_config.mouse_raw` | int16 / 鼠标原始位移 | X或Y单次位移绝对值超过此值时接管键鼠；鼠标按钮的新变化同样可接管。 |
| `chassis_config.turn.wheel_trigger_raw` | int32 / 原始通道值 | 上拨调头门槛；原始拨轮严格大于此值才登记请求。 |
| `chassis_config.turn.wheel_rearm_raw` | int32 / 原始通道值 | 原始拨轮回到此值及以下时，允许下次登记调头。 |

调头参数由 `ChassisTurnConfig_Init()` 加载；鼠标连发门槛位于上板 `shoot_config.mouse_continuous_threshold_ms`。

触发幅值使用正数，回中幅值小于触发幅值，触发幅值小于遥控有效满量程。上板 `cloud_config.yaw.turn` 与下板 `chassis_config.turn` 的拨轮阈值同步调整。参数只改变门槛，升降、保险和失联联锁仍参与判断。

## 软复位诊断

| Watch表达式 | 含义 |
| --- | --- |
| `control_reset_state.phase` | 0正常、1准备、2预提交、3提交重启、4取消握手 |
| `control_reset_state.sequence` | 当前复位事务序号，两板应匹配 |
| `control_reset_state.abort_count` | 本次上电后的取消次数 |
| `control_reset_state.failed_phase` | 最近取消前的阶段 |

握手取消后回到0，遥控在线且松开复位组合后恢复操作；流程见 [双板复位](14_比赛操作与双板复位.md#双板复位)。

## 观察方法

- 表格中的完整表达式可逐项加入 Keil Watch；数组示例使用有效下标，其他元素按本页说明替换。
- 两板分别加载对应 AXF。重新编译后更新调试符号；JScope 等按地址采样的工具需重新载入 ELF。
- 确认程序运行且调试器启用了运行时刷新。曲线观察用 JScope 或支持采样的内存工具，采样周期按要观察的动作选择。
- 单位区分转子 rpm、rad/s、deg/s、累计编码器计数和电流原始码。目标、指令与实际反馈分别记录。
- 数据时效同时查看在线、新鲜度、接收计数和时间戳。裁判结构保留最后有效值，过期后仍能看到旧数值。
- 文件内 `static` 变量在对应源文件作用域查看。找不到表达式时通过调试器 Symbols 定位；编译优化可能影响内部变量可见性。
- Watch 用于观察；应用读取多成员状态继续使用快照接口。

## 常见问题排查

| 现象 | 建议观察顺序 |
| --- | --- |
| 底盘不动 | `rc_task_frame_count` → 遥控模式 → `chassis_turnaround_pending` → C2 锁车帧 → `chassis_power_state.referee_output_allowed` → 各轮反馈有效性 |
| 个别轮子响应差 | `chassis_power_state.target_speed_rpm[0]`、`chassis_power_state.speed_rpm[0]` → `chassis_power_state.request_raw[0]`、`chassis_power_state.output_raw[0]` → `chassis_power_state.wheel_scale[0]`；下标替换为对应轮 |
| 功率预测与实测不一致 | `chassis_power_state.power_w` → 两条预测功率 → `chassis_power_state.learning_sample_aligned` → `chassis_power_model_state.loss`、`chassis_power_model_state.estimator.innovation` |
| 缓冲能量不变化 | `referee_state.message[7].rx_count`、`referee_state.message[7].fresh` → `referee_state.info.power_heat_data.buffer_energy` → `power_communication_state.control.raw[0]` |
| 超电是否收到使能 | `power_communication_config.cap_enabled` → `power_communication_state.control.raw[7]`、`power_communication_state.control.tx_count` → `power_communication_state.capacitor.discharge_available` |
| 裁判数据全零或不更新 | `referee_uart_diagnostics.received_byte_count` → `referee_state.diagnostics.valid_frame_count` → `referee_state.diagnostics.parsed_frame_count` → 目标命令 `rx_count`、`fresh` |
| 小陀螺无法开启 | `chassis_spin_block_reason` → 本地遥控模式与使能 → C1 新鲜度与许可 → IMU 在线状态 |
