# 底盘功率控制

## 文件和控制链

`chassis_power_control.[ch]` 是纯功率比例PI；`chassis_power.[ch]` 适配裁判、超电和电机；`chassis_power_estimate.[ch]` 保留电压×力矩电流诊断。四轮驱动在速度/位置/直接电流发送前统一调用 `ChassisPower_Apply`，不能只在一个底盘模式调用限流。

```text
四轮PID电流 → 单轮电流限幅 → 四轮共用功率比例 → 0x200发送
裁判上限−reserve_w → PI目标 ← 超电0x211实测功率
```

超电 `chassis_power_raw` 已按本机实测确认直接为W。功率闭环使用超电上报的底盘功率；电容电压×C620力矩电流保存在estimate字段，作为乘积估算观察值。

## 限流策略

相对误差 `e=(target−power)/target`，误差死区内置零。PI积分与输出限制在0～1，输出饱和时避免同方向积分；四轮电流统一乘该比例。下降比例可立即执行，上升受recovery_per_s限制。只有新超电样本更新PI，同一帧重复读不累计积分；目标改变可重算比例项。四轮请求全零时保持比例，负功率按零消耗参与闭环，但观察值保留符号。

速度/位置PID在后级限流加重饱和时恢复本次新增积分；误差使积分退出饱和时允许回退。统一缩放维持各轮指令比例，不是针对每个轮子分别估计功率。

## 裁判和失效策略

裁判状态新鲜时用chassis_power_limit，扣余量生成target；未收到裁判用offline_limit_w，已有旧裁判值则备用上限不超过最后有效上限。明确关闭底盘输出或有效上限为零时输出零，超时不会把最后断电许可自动放开。

超电功率反馈过期时四轮按最大指令共同缩小到offline_current_limit，重置功率PI。配置非法输出零。enabled关闭仅停用功率缩放，裁判明确禁止输出仍生效。

## Keil变量

| 变量 | 含义 |
| --- | --- |
| `referee_state.info.robot_status.chassis_power_limit` | 裁判下发上限，W |
| `chassis_power_state.referee_limit_w/referee_fresh/referee_output_allowed` | 最近裁判值、新鲜度、观察许可 |
| `power_w/target_w` | 超电功率/扣余量目标，W |
| `current_scale/limited/control_config_valid` | 四轮比例、是否收电流、配置是否有效 |
| `power_feedback_valid/power_sample_count/power_rx_ms` | 功率反馈有效性、样本计数和时间 |
| `request_raw[4]/output_raw[4]` | 功率限制前后电流码 |
| `estimate.*` | 旧乘积诊断，不参与闭环 |

## 调参与限制

参数在chassis_power_control_config：reserve_w、deadband_w、kp、ki_per_s、recovery_per_s、initial_scale、offline_limit_w、offline_current_limit。见 [完整配置表](11_配置与调参.md)。反馈限流要等功率测量返回才收电流，猛烈加减速可能暂超；目前没有电机模型、缓冲能量策略或电流突增斜坡，不能保证瞬时不超限。

纯PI可复用于已知真实功率反馈的负载控制，移植配置和控制器实例后提供W与秒单位dt。适配层必须重新确认测量位置、符号、反馈频率、裁判协议和驱动统一出口。不要为负功率取绝对值；超电侧回馈不一定经过裁判测量点。
