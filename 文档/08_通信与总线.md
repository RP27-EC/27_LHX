# 上板板间通信

## 接收与拼帧

文件 `bottom_driven/communication/board/communication.[ch]`。Init设置CAN2精确ID过滤器。回调保存每个D帧快照，D1→D2→D3按窗口拼18字节DBUS，校验通道与拨杆后发布；控制任务通过RC接口读取。错误顺序/超时拼帧不能当有效遥控。

拼帧和遥控数据的有效期共用 `communication_config.timeout_ms`，从 D1 接收时刻开始计算。D2、D3 不续期，达到超时边界就丢弃本轮拼帧；任务在缺片期间也会清理过期分片。新 D1 会替换未完成的旧拼帧并重新计时。

完整快照保留 D1 接收时间，任务发布前再次检查有效期。等待任务期间过期的快照直接丢弃，不增加有效帧计数、不刷新在线时间。计时使用无符号时间差，支持系统毫秒计数溢出。

## 两板协议

板间总线是上板CAN2与下板FDCAN2，标准11位ID、经典CAN、8字节，小端字段。电机DJI群组指令使用大端，不能把两种协议的字节序混用。

| ID | 方向 | 数据与含义 |
| --- | --- | --- |
| D1/D2/D3 | 下→上 | 原始DBUS第0～7、8～15、16～17字节；D3余位补零，上板按顺序拼帧 |
| D4 | 下→上 | 字节0～1有符号int16，乘0.01得deg/s；字节2 bit0有效 |
| D5 | 下→上 | 四个小端int16，四轮转子rpm |
| D6 | 下→上 | 字节0～1当前热量、2～3热量上限、4～5每秒冷却量，均uint16小端；字节6 bit0数据有效、bit1发射电源许可；字节7热量更新序号 |
| D7 | 下→上 | 字节0～1实测弹速、2～3弹速上限，uint16×0.01m/s；字节4～5测速序号，uint16小端；字节6 bit0测速有效、bit1上限有效；字节7样本年龄，向上取整为10ms单位 |
| C1 | 上→下 | 字节0～1为机械相对Yaw角，int16×0.01°；字节2为状态位 |
| C2 | 上→下 | 字节0标识0xA6，字节1 bit0校准锁车，字节2请求序号 |

C1字节2：bit0角有效、bit1调头中、bit2允许调头、bit3允许自旋、bit4上板选中小陀螺、bit5升降低位禁止云台模式。模式位与角度有效位独立，不能仅凭角有效就自旋。C2只用于升降校准，普通升降不锁车。各种状态分别检查超时，不应把最后值永久当作有效值。

D4在下板底盘任务持续发送，包括机械模式与停车状态；无效时明确发无效位。上板机械Yaw读取D4作速度目标前馈，D5目前主要是轮速接口与观察，不能据此认定已实现防打滑。

D6由下板裁判任务按 `remote_config.heat_tx_period_ms` 转发。机器人状态和热量消息都新鲜时才置有效位，重复转发保持热量序号不变。上板通过 `Communication_GetHeatSnapshot()` 读取，再按 `shoot_heat_config.referee_timeout_ms` 检查板间帧超时。CAN2 bank 16同时放行D5/D6/D7，bank 15保留给Yaw电机，修改协议后两板同步烧录。

D7按 `remote_config.shot_tx_period_ms` 转发主17mm枪管测速。测速和弹速上限分别置有效位；重复转发保持测速序号，更新原样本年龄。上板通过 `Communication_GetShotSnapshot()` 读取并恢复本板时间域中的测速时刻，再由发射模块检查D7超时、测速年龄、启动和调速稳定时间。新增D7无需修改外设引脚。

## 参数和移植

`communication_config` 指定遥控和底盘角速度的接收有效期，具体字段见配置表。移植需配置物理总线、标准帧过滤、FIFO中断和唯一回调，调用Init，周期服务，统一单位/字节序/有效位。改变协议或ID应同时修改两板、过滤器、超时以及文档。不要用阻塞等待代替发送失败处理。

## 接口与排查补充

业务读取原始帧使用 `Communication_CAN_GetLatest`。`Communication_CAN_GetChassisYawRateState` 同时返回角速度和收帧时间，并检查 D4 有效位与独立超时。

## 常用观察变量

`board_link.data.frames` 通过模块数据指针读取，数组 0～6 对应 D1～D7。接收次数记录原始帧；遥控解析结果另看 `communication_rc_valid_count`。

| Watch 表达式 | 单位 / 类型 | 含义 |
| --- | --- | --- |
| `communication_rc_online` | bool | 遥控拼帧、解析及超时检查后的在线状态。 |
| `communication_rc_valid_count` | 帧 | 完整且有效的遥控快照解析次数。 |
| `communication_rc_last_valid_ms` | ms | 最近一次有效遥控快照的原接收时间。 |
| `communication_rc_assembly_error_count` | 次 | 缺片、顺序、填充或过期等拼帧错误累计数。 |
| `board_link.data.frames[0].rx_count` | 帧 | D1 原始帧接收次数。 |
| `board_link.data.frames[3].rx_count` | 帧 | D4 底盘角速度帧接收次数。 |
| `board_link.data.frames[3].last_rx_ms` | ms | 最近 D4 接收时间。 |
| `board_link.data.frames[5].rx_count` | 帧 | D6 热量帧接收次数。 |
| `board_link.data.frames[5].last_rx_ms` | ms | 最近 D6 接收时间。 |
| `board_link.data.frames[6].rx_count` | 帧 | D7 枪管测速帧接收次数。 |
| `board_link.data.frames[6].data[6]` | 位图 | D7 弹速有效位与上限有效位。 |
| `board_link.data.frames[6].data[7]` | 10 ms/码 | D7 原测速样本年龄，接收后的年龄由快照接口继续计算。 |

完整速查与观察方法见 [本板观察变量速查](00_观察变量速查.md)。
