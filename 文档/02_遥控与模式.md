# 上板遥控与模式

## 输入和输出

文件：`user/remote_state.[ch]`；输入来自 `Communication_RC_Get` 拼出的原始 DBUS，输出为 `RemoteState_t`。通信任务是状态写入者，云台、升降和发射各自读取快照。内部 `machine` 是静态模式记忆，不能当作公共接口。

## 模式与操作

| 输入 | 行为 | 条件 |
| --- | --- | --- |
| 左上 / 左中 / 左下 | 跟随 / 机械 / 机械且允许升降 | 小陀螺选中状态还受拨轮切换控制 |
| 普通模式右下 / 右中 / 右上 | 保险 / 摩擦轮待发 / 发射 | 首次上线先记档位，真实换档后布防 |
| 左下档右中 / 右下 | 升降高位 / 低位 | 初次进入只记档位，之后换档才给目标 |
| 拨轮正向 | 切换小陀螺选中状态 | 回中后再触发，物理进入需右杆保险 |
| 拨轮负向 | 请求调头 | 云台有许可且不在自旋；被禁止的旧请求不补执行 |
| V、Z、X | 键鼠接管、跟随、机械 | 按下沿触发 |
| G、Q、B | 小陀螺、调头、升降切换 | B 只在键鼠机械模式使用 |
| F、鼠标左键 | 摩擦轮、短按单发/长按连发 | 遥控小陀螺禁止发射，键鼠小陀螺允许 F/鼠标发射；实际供弹还需安全许可 |
| 鼠标右键 | 降低瞄准灵敏度 | 使用键鼠灵敏度参数 |

物理左下档关闭发射布防，右杆被升降占用；键鼠 B/F 独立，因此升降许可恢复后仍可重新布防。断联清通道、模式和输入边沿，重新上线不会把默认值变化误认成手动动作。

## 快照变量

| 成员 | 用途 |
| --- | --- |
| `mode.chassis` | `DISABLED/MECHANICAL/FOLLOW/SPIN`；选中模式不等于实际获得许可 |
| `mode.shooting` | `OFF/READY/SINGLE/CONTINUOUS` |
| `input.channel[5]` | 映射后的通道，原始中心偏移已扣除 |
| `input.keyboard_active/right_switch/lift_right_switch/right_up` | 输入来源、物理右杆、升降专用档位和射击触发状态 |
| `safety.online/shoot_armed/spin_enabled/lift_enabled` | 遥控有效性与本地布防；最终执行仍由各模块判断 |
| `event.shoot_single_request_count/lift_toggle_request_count` | 累计事件序号，任务比较变化消费，不应每周期清零 |

快照没有公开全局变量；业务代码使用 `RemoteState_Get(&state)`。调试器可在函数调用处观察局部 `remote`，或查看源文件内部静态状态，不建议为观察改动通信协议。

## 参数、排查与移植

键鼠灵敏度在 `keyboard_sensitivity_config`，触发与时间参数见配置表。出现发射锁住先看布防标志，再看升降许可，最后看电机在线。新增按键必须定义按下沿、松开再触发、断联清除规则；两板共享底盘模式的映射需同步修改。模块依赖当前 DBUS 类型、配置和临界区接口，不是完全独立的纯算法。
