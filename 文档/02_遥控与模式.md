# 下板遥控与模式

## 分层

`bottom_driven/telecontrol/telecontrol.[ch]` 负责UART5 DBUS双缓冲、完整18字节取帧、通道/拨杆校验和在线。`user/remote_state.[ch]` 负责本板模式和键鼠映射；解析任务更新，底盘任务用 `RemoteState_Get` 读快照。板间传原始DBUS，不能把下板映射后的结构体直接作为18字节转发。

## 变量

| 变量/成员 | 含义 |
| --- | --- |
| `rc_ctrl.rc.ch[5]/s[2]` | 原始解析通道和左/右杆；通道已扣中心值 |
| `rc_ctrl.mouse/key` | 鼠标位移/按键与键盘位图 |
| `rc_rx_frame_count/rc_rx_last_size` | 底层接收事件统计 |
| `rc_task_frame_count` | 任务成功解析计数，区别于只收到字节 |
| `RemoteState_t.mode.chassis` | `DISABLED/MECHANICAL/FOLLOW/SPIN` |
| `input.channel[5]/keyboard_active` | 本板使用的映射通道与输入来源 |
| `safety.online/spin_enabled` | 输入有效性、本地手动自旋使能 |
| `event.turnaround_request_count` | 调头事件序号，供底盘消费 |

状态快照没有公开全局变量，通过Get接口读。`RC_TakeFrame` 无新帧返回false；在线状态由最后有效帧时间判断。

## 操作和边沿

物理左上跟随、左中/左下机械；左下升降与发射互斥由上板执行。拨轮正向切换小陀螺，需回中才能再次切换；负向产生调头事件。自旋须本地右杆在模式内换档且处于上档，另需上板C1许可。许可丢失立即停转，已执行过自旋后持续失去许可则要求重新布防。

键鼠V切接管，Z/X选跟随/机械，W/S和A/D平移，Shift/Ctrl改变速度，鼠标X/Y云台输入，右键降低瞄准灵敏度，G切小陀螺，Q调头。上板独立处理F/鼠标左键发射、机械模式B升降。断联清边沿记忆，初次上线只记录档位，禁止旧输入自动触发动作。

## 外设与移植

UART5为DBUS专用，实际配置100000、带偶校验与停止位；HAL字长包含校验位，不能套裁判115200 8N1配置。当前接收用DMA1 Stream0和UART IDLE自定义处理，裁判另用USART1循环DMA。

同协议接收机可复用帧解析；移植UART接收需核对句柄、DMA双缓冲、IRQ分发与缓存可见性，使用TakeFrame/ParseFrame/MarkValidFrame流程。模式参数在remote_config与keyboard_sensitivity_config，改变共享模式映射时同步上板。
