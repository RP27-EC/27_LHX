# 下板遥控与模式

## 分层

`bottom_driven/telecontrol/telecontrol.[ch]` 负责UART5 DBUS双缓冲、完整18字节取帧、通道/拨杆校验和在线。`user/remote/remote_state.[ch]` 负责本板模式和键鼠映射；解析任务更新，底盘任务用 `RemoteState_Get` 读快照。板间保留原始18字节DBUS，并在D3扩展字段传下板选定的来源与模式。

## 操作与边沿

切换左杆后清除有效右档，必须重新拨右杆才接受对应功能；上线首帧和升降解锁后也重新等待。已执行的升降继续完成，左下档内新的右杆方向允许中途换向。有效右档保存在 `input_selector.right_action`，发布快照为 `remote_state.input.right_action`：0等待、1上、2下、3中，通过D3同步给上板。

完整映射见 [操作映射与双板复位](14_比赛操作与双板复位.md)。遥控左上/左中选惯性/机械，右下保险，右中、右上允许发射。正常档原调头侧拨轮改为切换小陀螺，回中后再拨可退出并保持惯性模式；另一侧仍用于发射。切换小陀螺时云台不执行调头。右中和右上换档保留已选自旋状态，右下保险取消自旋。左下档右上升、右下降，右中时拨轮下保持触发复位、上调头。

键鼠保留Q调头、G小陀螺、F摩擦轮、Z/X惯性/机械、B切升降目标及原有移动和鼠标操作，Ctrl+R持续保持软复位。B从当前模式自动切机械并回安全零点，途中可再次按B反向。

模式和来源自动接管保持原规则。升降期间接受新的升降方向，其它模式和动作忽略；被忽略的输入不排队。退出小陀螺保持惯性，下一次明确拨杆选档或键鼠选模式再改变。

## 外设与移植

UART5为DBUS专用，实际配置100000、带偶校验与停止位；HAL字长包含校验位，不能套裁判115200 8N1配置。当前接收用DMA1 Stream0和UART IDLE自定义处理，裁判另用USART1循环DMA。

同协议接收机可复用帧解析；移植UART接收需核对句柄、DMA双缓冲、IRQ分发与缓存可见性，使用TakeFrame/ParseFrame/MarkValidFrame流程。模式参数在remote_config与keyboard_sensitivity_config，改变共享模式映射时同步上板。

## 接口与排查补充

业务读取映射状态使用快照接口。`RC_TakeFrame` 无新帧时返回 false；遥控在线状态由最后有效帧时间判断。

## 常用观察变量

`remote_state` 位于 `user/remote/remote_state.c`，为文件内静态快照。`rc_ctrl` 是物理 DBUS 解析值，映射后的输入另看 `remote_state.input`。

| Watch 表达式 | 单位 / 类型 | 含义 |
| --- | --- | --- |
| `rc_ctrl.rc.ch[0]` | 通道原值 | 右杆左右；[1] 右杆上下，[2] 左杆左右，[3] 左杆上下，[4] 拨轮。 |
| `rc_ctrl.rc.s[0]` | uint8 | 左拨杆；[1] 为右拨杆。上=1，中=3，下=2。 |
| `rc_ctrl.mouse.x` | 鼠标原值 | 鼠标水平位移。 |
| `rc_ctrl.mouse.y` | 鼠标原值 | 鼠标垂直位移。 |
| `rc_ctrl.mouse.left` | bool | 鼠标左键按下。 |
| `rc_ctrl.key` | 位图 | DBUS 键盘按键状态。 |
| `rc_rx_last_size` | 字节 | 最近 UART 空闲事件收到的数据长度。 |
| `rc_rx_frame_count` | 帧 | 底层识别的完整 DBUS 帧数。 |
| `rc_task_frame_count` | 帧 | 任务成功校验和解析的帧数。 |
| `remote_state.mode.chassis` | 枚举 | 请求模式：0 停用、1 机械、2 跟随、3 小陀螺。 |
| `remote_state.input.channel[0]` | 通道原值 | 映射后的控制通道；有效下标为 0～4。 |
| `remote_state.input.keyboard_active` | bool | 当前使用键鼠输入。 |
| `remote_state.safety.online` | bool | 本地遥控有效。 |
| `remote_state.safety.spin_enabled` | bool | 本地小陀螺已手动使能。 |
| `remote_state.event.turnaround_request_count` | 序号 | 拨轮或 Q 键调头事件累计数。 |

完整速查与观察方法见 [本板观察变量速查](00_观察变量速查.md)。
