# 上板遥控与模式

## 输入和输出

文件：`user/remote/remote_state.[ch]`；输入来自 `Communication_RC_Get` 拼出的原始 DBUS，输出为 `RemoteState_t`。通信任务是状态写入者，云台、升降和发射各自读取快照。内部 `machine` 是静态模式记忆，不能当作公共接口。

## 模式与操作

| 输入 | 行为 | 条件 |
| --- | --- | --- |
| 左上 / 左中 / 左下 | 跟随 / 机械 / 机械且允许升降 | 小陀螺选中状态还受拨轮切换控制 |
| 普通模式右下 / 右中 / 右上 | 保险 / 摩擦轮待发 / 发射 | 首次上线先记档位，真实换档后布防 |
| 左下档右中 / 右下 | 升降高位 / 低位 | 初次进入只记档位，之后换档才给目标 |
| 拨轮正向 | 切换小陀螺选中状态 | 回中后再触发，物理进入需右杆保险 |
| 拨轮负向 | 请求调头 | 云台有许可且不在自旋；被禁止的旧请求不补执行 |
| V、Z、X | 键鼠接管、跟随、机械 | 按下沿触发 |
| G、Q、B | 小陀螺、调头、升降切换 | B 只在键鼠机械模式使用 |
| F、鼠标左键 | 摩擦轮、短按单发/长按连发 | 遥控小陀螺禁止发射，键鼠小陀螺允许 F/鼠标发射；实际供弹还需安全许可 |
| 鼠标右键 | 降低瞄准灵敏度 | 使用键鼠灵敏度参数 |

物理左下档关闭发射布防，右杆被升降占用；键鼠 B/F 独立，因此升降许可恢复后仍可重新布防。断联清通道、模式和输入边沿，重新上线不会把默认值变化误认成手动动作。

## 参数、排查与移植

键鼠灵敏度在 `keyboard_sensitivity_config`，触发与时间参数见配置表。出现发射锁住先看布防标志，再看升降许可，最后看电机在线。新增按键必须定义按下沿、松开再触发、断联清除规则；两板共享底盘模式的映射需同步修改。模块依赖当前 DBUS 类型、配置和临界区接口，不是完全独立的纯算法。

## 常用观察变量

`remote_state` 是 `user/remote/remote_state.c` 内的静态变量，在该文件作用域查看。原始拨杆和映射后的模式分开观察；最终许可再查看升降和发射模块。

| Watch 表达式 | 单位 / 类型 | 含义 |
| --- | --- | --- |
| `communication_rc_online` | bool | 下板遥控数据完成拼帧、解析且尚未超时。 |
| `communication_rc.rc.ch[0]` | 通道原值 | 右摇杆左右；[1] 右杆上下，[2] 左杆左右，[3] 左杆上下，[4] 拨轮。 |
| `communication_rc.rc.s[0]` | uint8 | 左拨杆；[1] 为右拨杆。上=1，中=3，下=2。 |
| `communication_rc.key` | 位图 | DBUS 键盘按键状态。 |
| `remote_state.mode.chassis` | 枚举 | 映射后的请求模式：0 停用、1 机械、2 跟随、3 小陀螺。 |
| `remote_state.mode.shooting` | 枚举 | 请求发射模式：0 保险、1 待发、2 单发、3 连发。 |
| `remote_state.input.channel[0]` | 通道原值 | 本板使用的映射输入；有效下标为 0～4。 |
| `remote_state.input.keyboard_active` | bool | 当前采用键鼠输入。 |
| `remote_state.safety.online` | bool | 遥控输入有效。 |
| `remote_state.safety.shoot_armed` | bool | 本地已完成发射手动布防。 |
| `remote_state.safety.spin_enabled` | bool | 本地已完成小陀螺手动使能。 |
| `remote_state.safety.lift_enabled` | bool | 当前允许接收升降操作。 |
| `remote_state.event.shoot_single_request_count` | 次 | 键鼠短按单发事件累计序号。 |
| `remote_state.event.lift_toggle_request_count` | 次 | 键鼠升降切换事件累计序号。 |

完整速查与观察方法见 [本板观察变量速查](00_观察变量速查.md)。
