# 操作映射与双板复位

## 遥控器

左拨杆切档时，原右档立即失效；右拨杆必须在新左档内再次变化，对应功能才允许执行。右杆保持上档切到左下不会自动上升，保持上档切到正常档不会自动自旋或开轮。两杆同时变化时以左杆切档为准，之后还需新拨右杆。上线首帧同样先等待右杆变化。已开始的升降沿用原目标，途中重新拨右杆仍可换向。

| 左拨杆 | 右下 | 右中 | 右上 |
| --- | --- | --- | --- |
| 上 | 惯性模式，禁止发射及自旋 | 惯性模式，允许发射，拨轮切自旋 | 惯性模式，允许发射，拨轮切自旋 |
| 中 | 机械模式，禁止发射及自旋 | 机械模式，允许发射，拨轮切自旋 | 机械模式，允许发射，拨轮切自旋 |
| 下 | 下降至低位 | 机械保持及功能操作 | 上升至高位 |

左上、左中档：拨轮下拨超过阈值登记一发，持续超过连发时间转连发；右下保险时不接受供弹。原调头侧拨轮超过 `input_control_config.spin_wheel.trigger_raw` 时切换小陀螺，回到释放范围后再次拨动可退出；长时间拨住只触发一次。切换时云台不执行调头，退出后保持惯性模式。右上档仅保留发射许可，右中和右上换档保留已选自旋状态；右下保险取消自旋。

遥控右中档首次发射开摩擦轮，停射后保持转速，保险、失联和安全许可撤销时停轮。遥控右上档默认关轮，与遥控小陀螺一样按发射需求开停轮：短按完成已登记单发后关轮，连发松开后关轮。启动后仍需轮速稳定才供弹。实际开停轮由上板发射任务执行。

左下右中：拨轮下拨超过阈值并保持超过复位时间，发起两板软复位；向上拨为调头。左下右上、右下只接收对应升降方向，拨轮不触发调头或发射。

小陀螺退出后保持惯性模式。左杆仍在中档时，摇杆移动不会改回机械；下一次右拨杆换档再按左杆位置选模式。左拨杆重新选档同样按新档位处理。

## 键鼠

保留原有按键：WASD移动，Shift加速、Ctrl慢速，鼠标控制瞄准，右键精瞄，左键自动开轮、短按单发和长按连发；F切摩擦轮，G切小陀螺，Q调头，Z/X选惯性/机械，B切升降高低目标。Ctrl+R保持超过复位时间执行双板主控重启。

B可从惯性或小陀螺模式发起升降，自动切机械、Yaw就近回物理机械零点，Pitch满足安全角度后运行。退出小陀螺保持惯性模式。

## 升降与输入消费

- 升降前先自动切机械并回安全零点。
- 途中允许左下档的新上升、下降指令；键鼠再次按B切换目标方向。
- 其它模式、调头和发射操作在升降期间忽略，不打断当前升降。
- 到位后使用当前控制快照；忽略的边沿不补执行，下一次升降仍须重新拨杆或按B。
- 升降期间保持着的调头、发射输入须先回中或松开，再触发新动作。
- 失联、复位和电机反馈失效优先停止。反馈恢复后不补执行掉线期间的待执行升降请求。

## 单连发

拨轮与鼠标在按下时登记首发，双轮达到稳定转速后供弹；短拨、短按请求保留至本发完成。持续按下超过对应连发门槛转连发。首发沿用同一次请求和热量预留，切换时不会额外补一发。热量及轮速就绪继续控制实际供弹。

切保险、失联或进入升降时清掉供弹请求。许可恢复后需要新的手动布防动作，拨轮新的下拨、鼠标新的按下均可布防。

## 双板复位

键盘Ctrl+R；遥控左下、右中、拨轮向下超过幅值门槛。连续保持超过下板 `input_control_config.reset_hold_ms` 后发起握手，两板默认统一为两秒。切换两种组合时重新累计保持时间。进入组合先停止控制；松开后才能再次触发，开机已保持组合时先等待松开。

下板发停机准备，上板停输出并应答，经过预提交、提交后两板调用 `NVIC_SystemReset()`，重新执行初始化与校准。复位应答由上板通信任务独立重发，云台是否完成归中、电机是否在线不参与握手推进。

提交前等待超时或对板取消时进入阶段4，重复发送取消后回到空闲；上板收到对板空闲、重新上电或取消时撤销未提交的锁存。遥控在线且复位组合已松开后恢复正常输入，重新复位仍须新的长按。已进入提交阶段则继续重启，旧空闲帧和新请求不能打断；重启后残留提交帧不重复触发。

当前提交前超时为2秒、取消重复发送为100ms；定义在两板 `control_input.h` 的 `RP_RESET_*` 宏中。阶段1等待停机稳定后才应答；上板提交后等待50ms重启，下板等待100ms。CAN持续断开时无法保证两板同时收到重启提交。

出现“遥控开着但电机不使能”时，先观察两板 `control_reset_state.phase`：正常运行应为0。`abort_count` 持续增加时检查两板程序版本、C1/D3通信和应答；`failed_phase` 保存最近取消前的阶段。

## 参数与观察

默认值位于各板 `config/application_config.c`，输入辅助实现位于 `user/remote/control_input.h`。两板副本和相关阈值保持一致。

| 参数 | 用途 |
| --- | --- |
| `input_control_config.wheel.trigger_raw` | 遥控发射及复位的拨轮幅值门槛 |
| `input_control_config.wheel.rearm_raw` | 发射拨轮回中范围 |
| `input_control_config.wheel.continuous_ms` | 拨轮持续发射转连发时间 |
| `input_control_config.spin_wheel.trigger_raw` | 原调头侧拨轮切换小陀螺的正向触发门槛 |
| `input_control_config.spin_wheel.rearm_raw` | 拨轮回中释放门槛，释放后允许再次切换 |
| `input_control_config.reset_hold_ms` | 两种复位组合的持续时间 |
| `input_control_config.takeover_raw/change_raw/mouse_raw` | 来源接管的幅值、累计变化及鼠标位移门槛 |
| `shoot_config.mouse_continuous_threshold_ms` | 鼠标持续按下转连发时间，上板配置 |
| `cloud_config.yaw.turn.wheel_trigger_raw/wheel_rearm_raw` | 上板升降待机档调头的触发及回中门槛 |
| `chassis_config.turn.wheel_trigger_raw/wheel_rearm_raw` | 下板升降待机档同一调头操作的触发及回中门槛 |

| 观察变量 | 用途 |
| --- | --- |
| `remote_state.mode.chassis` | 当前请求模式，0停用、1机械、2惯性、3小陀螺；静态快照位于遥控文件 |
| `remote_state.mode.shooting` | 上板发射模式，0保险、1待发、2单发、3连发 |
| `remote_state.event.shoot_single_request_count` | 上板拨轮或鼠标登记的首发序号 |
| `remote_state.event.lift_motion_request_count` | 上板遥控方向请求序号 |
| `remote_state.event.lift_toggle_request_count` | 上板B升降请求序号 |
| `control_reset_state.phase/sequence` | 复位握手阶段和事务序号，正常运行phase为0 |
| `control_reset_state.abort_count` | 本次上电后未提交即取消的次数 |
| `control_reset_state.failed_phase` | 最近取消前的握手阶段 |
| `lift_hold_target_encoder_total` | 上板升降当前累计目标，位于升降文件 |
| `lift_wait_reason` | 上板升降等待原因 |
| `shoot_control_state.ready.ready/paused` | 上板轮速就绪和供弹暂停状态 |

本机验证“键位映射”组检查九档组合、单连发、方向反转、忽略输入和复位边界；执行器与反馈使用桩，实车转速、方向和总线时序需上板核对。两板同步烧录。

遗留状态清理与整体时序检查见 [控制逻辑静态检查](../../控制逻辑静态检查.md)。
