# 上板工程说明

本文以当前 `infantry_up` 代码为准，说明控制结构、运行逻辑和主要调参入口。上板负责云台两轴、升降机、发射机构，以及与下板交换状态；遥控器原始 DBUS 帧由下板转发。

## 工程结构

| 目录或文件 | 职责 |
| --- | --- |
| `Core/Src/main.c`、`Core/Src/freertos.c` | CubeMX 外设启动、驱动初始化和三个任务的创建；引脚、时钟等生成代码在 `Core`。 |
| `user/upper_tasks.c` | 板间通信、云台/升降、发射三个周期任务的入口及超期统计。 |
| `user/remote_state.c` | 遥控拨杆、拨轮、键鼠的边沿检测和模式状态机；发布原子状态快照。 |
| `user/cloud_terrace.c` | 云台归中、Yaw/Pitch 控制、调头及向下板发送 Yaw 状态。 |
| `user/lift_control.c` | 升降校准、高低位、角度联锁、堵转与行程保护。 |
| `user/shoot_control.c` | 摩擦轮、单发/连发、拨盘堵转退让和键鼠射击事件。 |
| `user/application_config.[ch]` | 云台、升降、发射、键鼠等应用参数；启动时初始化一次，`volatile` 结构体可在调试器中调参。 |
| `bottom_driven/communication/communication.[ch]` | CAN2 板间收发、DBUS 三帧拼接/解析、超时判定。 |
| `bottom_driven/motor/` | 4310、3508、2006、4005 的 CAN、反馈及底层闭环；4310 已归入同一电机目录。 |
| `bottom_driven/IMU/` | BMI088 SPI 读取、陀螺零偏、姿态四元数和 Yaw 角速度。 |
| `bottom_driven/peripheral_config.[ch]` | 电机、IMU、CAN 通信等底层参数。 |
| `algorithms_library/PID.[ch]` | 通用 PID 计算及运行中参数更新。 |
| `MDK-ARM/` | Keil 工程；`Drivers/`、`Middlewares/` 为 HAL/CMSIS/FreeRTOS 依赖。 |

启动顺序见 `Core/Src/main.c`：CubeMX 外设初始化 → 两类配置结构体赋默认值 → IMU → 两轴 4310 → 摩擦轮 3508 → 升降 2006 → 拨盘 4005 → CAN2 板间通信 → FreeRTOS。驱动初始化失败会进入 `Error_Handler()`。

## 周期任务与数据流

| 任务 | 默认周期 | 主要处理 |
| --- | --- | --- |
| `communication` | 4 tick | 接收 D1～D3，解析遥控，更新 `RemoteState_t`。 |
| `gimbalControl` | 4 tick | 更新上板 IMU → 云台控制 → 2006 心跳 → 升降控制。 |
| `shootControl` | 4 tick | 摩擦轮/拨盘心跳、射击安全条件、发射状态机。 |

任务周期由 `application_config.c` 初始化，使用 `osDelayUntil`；`upper_task_timing` 保存超期次数。CAN1 FIFO0 中断统一分发 Pitch 4310、双摩擦轮 3508、升降 2006、拨盘 4005；CAN2 FIFO0 分发 Yaw 4310 和板间报文。遥控模式快照通过 `RemoteState_Get()` 原子读取，不在控制任务中直接解析 CAN 字节。

控制链路可概括为：下板 DBUS → D1～D3 → 上板 `communication` → `RemoteState_t` → 云台/升降/发射任务 → CAN1/CAN2 电机命令。云台归中后的机械相对 Yaw 角经 C1 返回下板，用于底盘跟随和移动坐标转换。

## 遥控与模式

三档拨杆原始值为上 `1`、中 `3`、下 `2`。上板状态机中，左上为底盘跟随云台；左中、左下为机械模式，其中左下另允许升降。拨轮正向越过阈值可切换小陀螺；小陀螺自旋还需右拨杆在该模式内发生过换档且处于上档。升降机未进入实测顶部安全区或仍在下降时，调头和小陀螺自旋均禁止；上电校准和正在自旋时也不接受调头。距低位目标 5 转子圈内，上板强制机械 Yaw 回到物理车头方向，并经 C1 通知下板停用跟随及小陀螺；上升离开低位 8 圈后解除。阈值可在 `lift_config` 调整。

非升降状态下，右拨杆下档为发射保险，中档仅转摩擦轮，上档执行发射：跟随模式为连发，机械模式为单发。初次上线只记录右拨杆位置，必须换档后才给发射布防；左下升降档会强制关闭发射。拨盘离线时，允许摩擦轮待发，但不供弹。

键鼠按键与生效条件详见下方“操作速查与边沿约束”；可调灵敏度见 `keyboard_sensitivity_config`。

## 云台控制

两轴均为达妙 4310 MIT 协议：Pitch 在 CAN1，控制/反馈 ID 为 `0x001/0x011`；Yaw 在 CAN2，为 `0x002/0x012`。两轴必须都在线，常规控制前先按 `yaw_home_rad`、`pitch_home_rad` 完成机械归中；任一轴掉线或遥控断联时退出闭环，断联会失能两轴。

| 场景 | Yaw 目标与控制 | Pitch 目标与控制 |
| --- | --- | --- |
| 未完成升降校准、机械模式 | Yaw 靠近选定的物理车头/车尾方向；收到升降指令后强制回物理车头 0°。编码器位置外环 + 上板陀螺仪速度内环。保持固定目标；机械保持使用单套 PID 和 ±1° 连续位置死区，内部保留速度环制动。 | 摇杆积分改变编码器位置目标，全程位置—速度串级 PID；松杆保持当前目标，不切速控。 |
| 底盘跟随云台、小陀螺 | 摇杆积分生成惯性系 Yaw 角目标；上板 IMU 角度 PID 生成角速度目标，再用 IMU 角速度 PID 输出转矩。松杆保持原角目标。 | IMU 俯仰角外环 + 陀螺仪俯仰角速度内环；松杆保持惯性角目标，保留编码器机械限位。 |
| 调头 | Yaw 使用编码器位控到距当前最近的反向车头方向，连续到位后交回当前模式；调头时底盘由 C1 标志停车。 | 仍可按常规输入控制。 |

Pitch 有相对归中点的上下限，位置目标最多领先反馈 `pitch_target_lead_deg`；升降处于下降/低位时会提高允许下限。重力前馈为 `pitch_gravity_k × cos(相对归中点角度)`，默认 `k=1.1 N·m`，不再使用额外偏置或倍率。Pitch 机械模式与归中 PID 在 `motor4310_config.pitch_pid`；跟随/小陀螺使用 `cloud_config.pitch_angle_*`、`pitch_rate_*` 独立 IMU PID，内环反馈为 `cos(roll)×gyro_y−sin(roll)×gyro_z` 换算 deg/s，不含姿态融合修正量。`pitch_imu_direction` 默认 +1，若 IMU 俯仰角与编码器增大方向相反则设为 -1。模式切换与 IMU 恢复从当前姿态接管，IMU 离线停止 Pitch 转矩控制。机械限位由实时编码器余量换算到 IMU 目标角，升降联锁强制机械模式。位置指令速率与重力系数在 `cloud_config`。上板 BMI088 的安装方向在 `IMU/imu.c` 处理，陀螺零偏上电标定；加速度用于姿态的重力方向修正，没有磁力计参与。机械模式的 Yaw 近点参数及固定速度前馈仍在 `motor4310_config`。

## 升降机

升降使用 M2006/C610：CAN1 回传 `0x204`，控制与摩擦轮共用 `0x200` 群组帧第 4 槽。上电累计转子编码器首帧为零，跨圈累计每圈 8192 计数。2006 采用速度 PID；应用层用位置误差比例换算目标转速，形成位置—速度串级控制。

遥控在线、2006 在线且 Yaw 回到**开机机械零点**并连续稳定后，自动请求 C2 锁车并向上找顶部。顶部只接受持续高电流低速的堵转判据；碰顶位置直接记为高位目标，低位目标仍为从碰顶位置向下 316 圈。碰顶后不回退，下一控制周期转入位控保持；从低位回高位的目标行程为 316 圈。校准完毕释放底盘锁车；日常升降不要求底盘轮速为零。

左下机械模式时，右拨杆中档选择高位、下档选择低位；进入该模式只记录当前档位，随后换档才执行。发出升降指令时，若 Yaw 已调头或偏离开机机械 0°，上板先取消调头并自动转回 0°，稳定超过 `yaw_stable_ms` 后再执行该次升降指令；归零期间 2006 保持停机。下降/低位还要求 Pitch 不低于零点，未满足时等待其抬起。升降中若 Yaw 再次偏离机械零点会暂停，回位后继续；遥控断联仍会取消待执行指令。上升、下降分别有电流/速度/时间及无进度堵转判据，另外限制上电累计转子圈数；故障状态与碰顶快照可查看 `lift_control_state`、`lift_wait_reason`、`lift_calibrated` 和 `LiftControl_GetStallSnapshot()`。调头后逻辑车头可反转，但升降对准条件仍以开机机械零点为准。

特殊动作以碰顶时记录的 `lift_top_contact_encoder_total` 为物理基准，不以“本次移动距离”推断位置。`lift_safety_state.from_top_turns` 为从机械顶点向下的累计转子圈数。顶部到位容差用 `top_arrival_tolerance_counts`，底部用 `position_tolerance_counts`。返回顶部时，只有在 `top_contact_window_turns` 范围内的真实碰顶才更新顶部基准并正常到位；更远处的堵转仍按故障停机。顶部放行范围用 `special_enter_from_top_turns`、`special_exit_from_top_turns` 形成迟滞。主动下降请求立即撤销许可；解除下降联锁的稳定时间用 `special_down_stop_stable_ms`。可在调试器查看 `position_valid`、`upper_zone`、`descending`、`yaw_home_required`、`special_allowed`、`spin_allowed`、`shoot_allowed`；快照有效期由 `special_state_timeout_ms` 决定。

| 情况 | 调头 | 小陀螺自旋 | 发射机构 | 云台/升降 |
| --- | --- | --- | --- | --- |
| 未校准、2006 离线、超出行程或安全快照超时 | 禁止 | 禁止 | 保险并停供弹 | 保留校准/故障保护；正常云台控制依自身状态 |
| 顶部安全区外，或有下降指令/持续实测下行 | 禁止 | 禁止 | 保险并停供弹 | 允许按条件上升；下降须 Yaw 对开机 0° 且 Pitch ≥0° |
| 顶部安全区内、位置及云台状态有效 | 允许，调头期间底盘停车 | 还需上板 IMU 有效及模式内手动使能 | 离开升降模式且重新手动布防后允许 | 高位上升目标可继续归位，Yaw 可自由瞄准 |

主动升降到位后，当周期撤销 Yaw 回零请求。离开升降档或将升降拨杆拨到停机档也会撤销旧请求；顶部未完全到位的目标可继续按保持速度归位，不再占用主动升降联锁。位于顶部放行区、没有主动升降请求时，位置保持电机无需完全停转，也不因保持运动重新锁存下降。新的下降请求仍立即阻止特殊动作，位置离开顶部放行区、低位、故障和离线仍禁止。

升降到位后仍保持累计编码器目标：位置误差换算为转子目标速度，再由 2006 速度 PID 执行。`position_tolerance_counts` 和 `top_arrival_tolerance_counts` 只用于结束主动升降，不是位置保持死区；容差内也持续纠偏。保持沿用 `position_kp_rad_s_per_turn`，速度不超过 `hold_speed_rad_s`，不使用 `position_min_speed_rad_s` 的最小启动速度。已经到位后切出升降档或拨到停机档保留原目标；中途取消运动则保持当时位置。保持点附近不按运动无进度判据报堵转，偏离到位范围后的回位仍检查堵转和行程限制；遥控断联、电机离线和故障仍停机。速度环积分能力由 `motor2006_config.speed_ki` 与 `speed_integral_limit` 共同决定，积分限幅为零时不会累积静态支撑力。

切出左下升降档不会自动执行原发射请求，许可恢复后重新拨动右杆才布防；中档到上档也有效，不要求必须先回下档。键鼠仍需让 `F` 从关闭重新切到开启。小陀螺首次手动启动可等待许可，不能因为等待时间较长而提前锁存；已经获得许可后持续失去许可，仍须重新手动使能。物理遥控可将右杆回到非上档再拨到上档，键鼠退出后再进入。

上板 `upper_shoot_block_reason` 显示发射阻止原因：遥控、升降许可、小陀螺互斥、重新布防、摩擦轮或拨盘离线。若为升降许可，查看 `lift_safety_state` 中的上述字段和 `lift_control_state`；下板小陀螺原因仍由 `chassis_spin_block_reason` 显示。

机械模式的调头和发射许可根据 4310 编码器姿态判断；机械 Yaw 保持的陀螺仪速度环及跟随/小陀螺惯性控制要求 IMU 在线。键鼠机械模式用 B 控制升降、F 控制摩擦轮，两者不共用拨杆，顶部许可恢复后可发射；物理左下档仍为升降专用。上板 IMU 允许最多约 12 ms 的短暂 SPI 丢帧，连续失败后判离线并停止惯性控制。

## 发射机构

两台 3508 摩擦轮在 CAN1 回传 `0x201/0x202`，速度 PID 使其等速反向。LK4005 拨盘使用 CAN1 `0x141`，上电首帧建立累计角度零点：单发增加一个拨弹目标（`65536` 计数），位置 PID → 速度 PID → `0xA1` 电流；连发直接由速度 PID 输出电流。单发和连发均监测低速高电流堵转，触发后反向退让、再追原目标。保险、只转摩擦轮或拨盘离线时，拨盘发送 `0xA1` 零电流；离线时每个发射周期重试，在线后恢复正常间隔。待发及供弹时，拨盘先于摩擦轮 `0x200` 入队，减少 CAN1 邮箱竞争；4005 收发间隔不足仍跳过本周期，不阻塞发射任务。

发射状态和计数集中在 `shoot_control_state`；`dial_motor_tx_diagnostics` 记录拨盘成功入队、收发间隔拦截、邮箱满、HAL 发送失败次数及最近电流命令。应用频率、堵转、连发速度在 `shoot_config`，3508/4005 的电流限幅、PID 与离线时间在 `peripheral_config.c`。

## 板间 CAN 协议

板间使用 CAN2、11 位标准 ID、经典 CAN 8 字节帧。小端多字节字段，发送和接收两侧均校验 ID/有效期。下板发上板：

| ID | 数据 |
| --- | --- |
| `0xD1` | DBUS 原始 18 字节的 `[0..7]`。 |
| `0xD2` | DBUS `[8..15]`。 |
| `0xD3` | DBUS `[16..17]`，余字节补零。上板按 D1→D2→D3 拼帧并校验。 |
| `0xD4` | 底盘 IMU 实测 Yaw 角速度：`int16`、单位 `0.01°/s`；字节 2 bit0 为有效标志。 |
| `0xD5` | 四轮实测转子速度：4 个小端 `int16`，单位 rpm。 |

上板发下板：`0xC1` 的字节 0～1 是机械归中后的 Yaw 相对角（`int16 × 0.01°`）；字节 2 的 bit0/bit1/bit2/bit3/bit4/bit5 分别为角度有效、正在调头、允许调头、允许小陀螺自旋、上板已选中小陀螺、升降低位禁止云台模式。角度暂不可用时仍发送禁止自旋的模式状态；下板自旋依据本地遥控档位和 C1 模式/许可位，不依赖角度有效位。持续失去许可后须重新手动布防。`0xC2` 的字节 0 为标识 `0xA6`，字节 1 bit0 请求锁车，字节 2 为请求序号。C2 锁车用于升降**校准**，下板超时自动释放；正常升降不锁车。

## 基础算法与维护入口

- PID：通用 `PID_Calc`，控制任务中以配置结构体调用 `PID_UpdateParameters`，可在线改增益、积分和输出限幅；配置初始化函数只在启动时调用一次。
- 角度：4310 和 2006 都处理跨圈累计；机械 Pitch/Yaw 用编码器；跟随/小陀螺 Pitch 用 IMU 俯仰姿态及角速度，Yaw 用 IMU 累计航向及角速度。
- 姿态：BMI088 陀螺积分 + 加速度重力修正的四元数解算；Yaw 无磁航向绝对参考，长期漂移需在调试时关注。
- 调参顺序：先核对 `RemoteState_t` 和 CAN 在线计数，再核对机械归中/IMU，最后调整 `application_config.c` 的外环与 `peripheral_config.c` 的驱动内环；不要用应用参数替代电机电流限幅。
- 关键观察量：`upper_task_timing`、`communication_rc_online`、`motor4310_data`、`gimbal_imu`、`lift_control_state`、`shoot_control_state`、`dial_motor_feedback`。`HAL_OK` 只说明 CAN 帧成功入队，并非电机执行确认。

| `V`；`Z` / `X` | 键鼠接管；跟随 / 机械 | 刚接管先沿用物理左拨杆模式，`Z/X` 可重新选择。 |

| `F`、鼠标左键 | 摩擦轮开关；单发/连发 | 顶部安全许可恢复后须让 `F` 从关闭重新切到开启；摩擦轮开启后左键短按松开记一发，按住超过 `mouse_continuous_threshold_ms`（默认 200 ms）改为连发。 |

## 开发中遇到的问题与当前处理

| 表现 | 原因或定位要点 | 当前处理、复查位置 |
| --- | --- | --- |
| 上板 CAN 中断不进入、复位后两板偶发断联 | 初始化/滤波/通知/启动时序、接收 ID 和 D1～D3 完整性都可能造成“遥控离线” | 检查 `communication.c` 的 CAN2 滤波及 FIFO 回调、接收计数、帧超时，再对照下板 FDCAN2 的发送/Bus-Off 恢复；不要仅凭发送 `HAL_OK` 判断链路通。 |
| Yaw 无反馈或结构体始终为零 | 曾把 Yaw 当作 Pitch 的 CAN ID；两轴实际在不同 CAN 总线 | Pitch `CAN1 0x001/0x011`，Yaw `CAN2 0x002/0x012`。先看两轴 `rx_count` 与在线，再看 PID 和使能；两轴需同时在线。 |
| 云台转动慢、跟随偏、松杆漂或机械近点震荡 | 机械相对角、惯性角、坐标转换与 PID 周期不能混用；过强重力/速度前馈也会造成偏移 | 机械 Yaw 用归中编码器与近点 PID、1° 死区；惯性稳向用上板 BMI088 的角度/角速度，Pitch 单独重力补偿。先核安装符号、机械零点与限位，再调环路。 |
| 升降碰顶后回退中误判堵转，校准状态为 `lift_wait_reason=5` | 回退阶段与正常堵转/行程保护相互影响 | 当前碰顶即记录高位并完成校准，**不回退**；低位为从碰顶位置向下 316 转。故障时看 `lift_control_state`、等待原因和快照，不要仅提高电流阈值。 |
| 升降已校准但不动，或调头后仍允许在反向车头升降 | 未满足开机机械零点的 Yaw 稳定时间、Pitch 限制、换档边沿或 2006 在线条件 | 升降前必须回到开机机械 Yaw 0°（不是调头后的逻辑 0°），稳定超过配置时间；下降/低位 Pitch ≥0°；角度短时越界会暂停，回位稳定后续行。检查 `lift_wait_reason`。 |
| 遥控一开拨盘离线、偶尔某次开机才可控制 | 4005 反馈/发令时隙与 CAN1 共总线任务时序，非单纯使能问题 | 4005 帧先于摩擦轮帧入队，离线时每周期重试零电流；仍不在线时对比 `dial_motor_tx_diagnostics` 的成功入队、间隔拦截和邮箱满计数，再看 `dial_motor_feedback.rx_count` 是否增加。摩擦轮可转不代表拨盘在线。 |
| 云台与发射放同任务后发射丢周期 | IMU/SPI 与云台运算挤占发射调度 | 两任务已分离，用 `osDelayUntil` 保持周期；观察 `upper_task_timing`。若改周期，堵转“周期数×任务周期”、PID `control_period_s` 和心跳/超时应同步复核。 |
| 整车似乎完全不响应 | 曾有电池欠压而非代码故障 | 先确认电池、供电、CAN 终端与电机使能，再查远端在线/任务计数，避免盲目改控制逻辑。 |

### 机械 Yaw 单套 PID 与 1° 位置死区

机械 Yaw 保持固定 0°/180°目标，升降请求仍强制物理 0°。全角度使用 `motor4310_config.position_*` 与 `speed_*` 同一套参数，取消近远点 PID 分段与插值；独立调头仍用 `yaw_turn_pid` 和 S 曲线。

`cloud_config.mechanical_yaw_deadzone_deg=1.0`。误差为 e 时送入位置环的有效误差为：e>1° 使用 e−1°，e<−1° 使用 e+1°，±1° 内为零。这是连续软死区，原机械目标不被改写，跨界不重置 PID。死区内仍执行速度环，根据实际速度计算制动转矩，不直接清零电机输出；当前 Ki、Kd 为零时，只有实际转速也为零才自然输出零。未校准时的机械归中不使用这个死区。

已撤销上板机械 Yaw 的底盘角速度前馈及其配置入口。D4 连续上报仍可用于通信观测，但不参与本次 Yaw 控制。机械保持也不叠加固定方向转矩前馈。调试查看 `cloud_yaw_mechanical_error_deg`、`motor4310_position_pids[1].Output`、`motor4310_speed_pids[1].Output`。

### 机械 Yaw 回正减速

机械保持在位置环与速度环之间增加平方根速度限制：`速度码上限 = mechanical_yaw_brake_speed_at_1deg_raw × sqrt(死区外剩余角度/1°)`，同时不超过原位置环速度上限。使用有效误差，保留原机械目标与死区，不改变 PID 增益。进入死区时位置环输出速度限幅为零，速度环仍按上板陀螺仪角速度输出制动转矩。

`cloud_config.mechanical_yaw_brake_speed_at_1deg_raw` 默认 40：剩余 1°允许 40、4°允许 80 个速度码。调小会更早减速，调大会更快；设为 0 关闭。这里直接使用 MIT 速度原始码，没有假设电机的速度量程。调试可看 `cloud_yaw_mechanical_speed_limit_raw` 和 `motor4310_position_pids[MOTOR4310_YAW].Output`。仅用于机械保持/机械回零；独立调头 S 曲线和惯性 Yaw 不使用此限制。实际超调仍受惯量、速度环和积分参数影响，需实车调试。

### 独立调头 S 曲线

调头采用五次多项式 `s=10u³−15u⁴+6u⁵`，从当前编码器角到最近的反向车头方向。两端轨迹速度、加速度为零，通过 `u=已执行时间/设定时长` 生成位置目标。只设置轨迹时长，不再配置速度、加速度和 jerk 三个参数。时长越短，目标速度和加速度越大，实际跟踪和超调仍需上板验证。

| 参数 | 默认值 | 作用 |
|---|---|---|
| `cloud_config.turn_duration_s` | 1.13 | 调头轨迹时长，s；仅动作开始时读取 |
| `motor4310_config.yaw_turn_pid` | 独立串级配置 | 仅调头使用，与机械保持分开 |

默认时长沿用此前调头的近似节奏。实际调头时间还包含跟踪收敛与稳定确认，发送失败或任务长间隔会延长轨迹执行时间。调头不叠加固定方向转矩前馈。轨迹结束后保持最终目标，满足 `turn_tolerance_deg`、`turn_speed_raw_max`、`turn_stable_cycles` 才报告完成并释放下板停车。升降归零请求、安全许可撤销、离线仍可取消调头；取消后不继续旧轨迹。时长需为有限值、处于 0.004～30 s 且不短于控制周期，否则拒绝启动；动作过程中修改时长只影响下一次调头。PID 可在线调节。调试变量为 `cloud_turn_progress`、`cloud_turn_duration_s`、`cloud_turn_target_deg`。

调头速度跟踪上限现在位于 `yaw_turn_pid.position_output_limit`，单位仍为原始速度码。

### 机械 Yaw 陀螺仪速度环

机械保持/升降回零的外环仍使用编码器位置和 `motor4310_config.position_*`，内环改用上板 `imu.yaw_rate_deg_s`（已滤波的 Z 轴角速度），不使用电机反馈速度。内环 PID 单独放在 `cloud_config.mechanical_yaw_rate_*`，默认 Kp=10、Ki=Kd=0，转矩上限 `mechanical_yaw_torque_limit_raw=1800`。上电机械归中和独立调头继续使用原驱动编码器速度环。

位置环与刹车包络的速度码乘 `mechanical_yaw_command_deg_s_per_raw` 得到目标 °/s，默认 1，即 40 个目标速度码对应 40°/s。这是可调的目标指令比例，并非 MIT 速度反馈量程换算。`mechanical_yaw_gyro_direction` 默认 +1，IMU 正方向与电机编码器相反时改为 -1。机械目标保持底盘相对角，而上板陀螺仪测量云台绝对角速度，底盘转动时外环需要产生角差来提供跟随速度，仍可能有动态跟随误差。

IMU 离线时停止机械 Yaw 转矩控制，保留机械目标；恢复时清除 PID 历史后继续回正。调试可看 `cloud_yaw_mechanical_gyro_online`、`cloud_yaw_rate_target_deg_s`、`cloud_yaw_rate_deg_s` 和 `cloud_yaw_torque_raw`。速度环单位及反馈来源已改变，需重新实车确认方向和增益。
