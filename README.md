# 下板工程说明

本文以当前 `infantry _down` 代码为准。下板接收 DBUS 遥控，驱动四轮麦克纳姆底盘，通过 FDCAN2 与上板交换遥控、云台角度和锁车状态；FDCAN1 同时连接底盘电机、超级电容和无线充。

## 工程结构

| 目录或文件 | 职责 |
| --- | --- |
| `Core/Src/main.c`、`Core/Src/freertos.c` | CubeMX 外设启动、任务创建；遥控解析、底盘控制、板间通信任务的入口。 |
| `bottom_driven/telecontrol/` | DBUS UART/DMA 接收、18 字节帧校验、遥控在线判断。 |
| `user/remote_state.[ch]` | 左/右拨杆、拨轮、键鼠边沿和底盘模式状态机，向底盘任务发布快照。 |
| `user/chassis/chassis.[ch]` | 麦轮逆解、机械模式、跟随、小陀螺、调头协同。 |
| `bottom_driven/communication/power_communication.[ch]` | 超级电容与无线充状态解析、基础电容控制帧；与电机共用 FDCAN1 收发接口。 |
| `user/application_config.[ch]` | 底盘、遥控任务和键鼠的应用参数；`user/chassis/` 仅保留底盘控制文件。 |
| `bottom_driven/communication/communication.[ch]` | FDCAN2 板间帧、C1/C2 接收、D1～D5 发送和 Bus-Off 恢复。 |
| `bottom_driven/communication/chassis_can.[ch]` | FDCAN1 电机/电容/无线充统一滤波、发送和接收分发。 |
| `bottom_driven/motor/motor3508.[ch]` | 四轮反馈、`0x200` 电流命令、速度 PID；保留位置串级接口。 |
| `bottom_driven/IMU/imu.[ch]` | BMI088 SPI、安装轴符号、陀螺零偏、四元数姿态和 Yaw 角速度。 |
| `bottom_driven/peripheral_config.[ch]` | 遥控、3508、IMU、CAN、超电等外设参数。 |
| `algorithms_library/PID.[ch]` | 通用 PID 算法。 |
| `MDK-ARM/` | Keil 工程；`Drivers/`、`Middlewares/` 为 HAL/CMSIS/FreeRTOS 依赖。 |

`main.c` 在 CubeMX 外设初始化后，先初始化应用/外设参数和电容状态，再启动底盘 3508、FDCAN1、FDCAN2、BMI088 与 DBUS 接收，最后启动 FreeRTOS。配置对象是 `volatile` 结构体，默认值仅在启动时写入一次，可在调试器中在线调整。

## 周期任务与控制链路

| 任务 | 默认周期 | 主要处理 |
| --- | --- | --- |
| `Control_Parsing` | 15 tick | 从 DBUS 接收缓冲取帧、解析并更新 `RemoteState_t`；检查遥控掉线。 |
| `motor3508` | 4 tick | BMI088 更新 → 读取遥控和 C1/C2 → 调头/锁车判定 → 底盘解算及四轮速度 PID；定期发送 D5。 |
| `communication` | 4 tick | FDCAN2 恢复服务、电容状态服务、转发 D1～D3；D4 由跟随控制按配置周期发送。 |

任务周期在 `application_config.c`，优先级在 `Core/Src/freertos.c`。遥控帧先由 UART/DMA 接收和校验，状态机再把拨杆/键鼠映射为通道及模式。上板云台机械角通过 C1 返回，下板根据模式将平移和旋转命令转换为四轮目标 rpm，电机驱动计算四轮 PID 电流并发送 FDCAN1 `0x200`。任何底盘轮反馈失效或遥控断联时，底盘发送零电流停车。

## 遥控、键鼠与安全状态

三档拨杆原始值：上 `1`、中 `3`、下 `2`。当前下板模式映射为左上“底盘跟随云台”，左中/左下“机械模式”；左下的升降选择在上板执行，下板仍维持机械底盘控制。拨轮正向越过 `spin_wheel_trigger_raw`，可在原模式与小陀螺间切换；需先回中才能再切。物理遥控小陀螺每次进入都要看到右拨杆换档，右上档才启用自旋；下板还要求上板 C1 明确许可。许可丢失后不会自动重启自旋，可在许可恢复后将右拨杆回到非上档再拨到上档；自旋关闭时仍可平移。上板报告升降低位时，即使本地选中跟随或小陀螺，下板也临时按机械模式驱动底盘；离开低位后恢复本地所选模式。

拨轮从中位向负向越过 `turn_wheel_trigger_raw` 产生调头事件。下板先停车等待上板 Yaw 约 180° 转向；C1 报告“正在调头”时持续停车，完成后立即解除，若上板始终未接管则按 `turn_ack_timeout_ms` 撤销预锁。小陀螺正在自旋或上板禁止调头时不触发。C2 有效锁车请求仅用于上板升降**校准**；超时后自动释放，正常升降不锁底盘。

键鼠按键见下方“完整操作映射”；键鼠输入和档位状态机在 `user/remote_state.c`，灵敏度在 `keyboard_sensitivity_config`。上板处理 `F`/鼠标左键发射与机械模式 `B` 升降，下板转发完整 DBUS 原始帧供两板各自解析。

## 底盘模式与基础算法

四轮电机为 3508/C620，FDCAN1 反馈 ID `0x201～0x204`，控制帧 `0x200`。正常底盘任务使用**转速 PID**，不是位置 PID；`Motor3508_PositionControl` 是驱动提供的独立接口，目前底盘模式未调用。任一轮超过 `offline_timeout_ms` 未回报，四轮整体停机。

麦轮逆解在 `Chassis_MecanumInverse()`：

```text
轮1 = 前进 - 左移 - 旋转
轮2 = 前进 + 左移 - 旋转
轮3 = -前进 - 左移 - 旋转
轮4 = -前进 + 左移 - 旋转
```

四轮结果按最大绝对值**等比例缩放**至 `max_motor_rpm`，保留平移与旋转分量比例，再由四个速度 PID 输出电流。

| 模式 | 平移与旋转目标 |
| --- | --- |
| 机械 | 平移摇杆按 C1 机械 Yaw 角从云台坐标转到底盘坐标；旋转由 `ch[0] × rotate_scale` 直接给出。C1 暂失效时沿用最近的正反车头方向。 |
| 跟随 | 将云台相对角按距 `0°/±180°` 最近的车头方向计算误差；死区后用角度比例项 + Yaw 遥控输入前馈生成底盘旋转分量，限幅、斜坡后做麦轮逆解。C1 或底盘 IMU 角速度失效时停轮。 |
| 小陀螺 | 平移按云台 Yaw 角旋转到底盘坐标；本地右拨杆已布防且 C1 模式/许可有效时，旋转分量向 `spin_rotate_rpm` 斜坡变化。明确禁止立即停转，C1 自旋状态超过 150 ms 未更新也停转；C1 角度无效时平移为零。 |
| 调头/校准锁车 | 四轮零电流；调头完成或校准锁车解除后恢复相应模式。 |

云台坐标到车体坐标使用二维旋转：`前进' = 前进·cosθ − 左移·sinθ`，`左移' = 前进·sinθ + 左移·cosθ`，其中 `θ` 为 C1 Yaw 机械相对角乘方向系数。跟随旋转目标为 `角误差 × follow_kp_rpm_per_deg + 摇杆前馈`，再经 `follow_max_rotate_rpm` 和 `follow_slew_rpm_per_tick` 限制。当前底盘 IMU 的 Yaw 角速度**不是**该旋转目标的速度 PID 反馈；它用于跟随输入有效性检查及 D4 上报。没有使用加速度积分得到的平移速度闭环。

BMI088 在上电静止采样陀螺零偏，运行中按配置的安装轴符号处理角速度和加速度；陀螺积分与加速度重力校正形成四元数、欧拉角，并将重力从世界系加速度中扣除。未接磁力计，不提供有磁航向锚定的九轴融合。

## 板间 FDCAN2 协议

两板使用 11 位标准 ID、经典 CAN、8 字节；下板 FDCAN2 仅放行 C1/C2，上板 CAN2 接收 D1～D5。多字节字段按小端。下板发送：

| ID | 内容与用途 |
| --- | --- |
| `0xD1`、`0xD2`、`0xD3` | 原始 DBUS `[0..7]`、`[8..15]`、`[16..17]`（D3 余字节补零）；按 4 tick 周期转发，遥控离线时不发送。 |
| `0xD4` | 底盘 IMU Yaw 角速度，字节 0～1 是 `int16 × 0.01°/s`，字节 2 bit0 表示有效。 |
| `0xD5` | 四个轮子的实时转子转速，4 个小端 `int16`，单位 rpm。 |

上板发送：`0xC1` 字节 0～1 为机械归中后的相对 Yaw 角（`int16 × 0.01°`），字节 2 bit0/bit1/bit2/bit3/bit4/bit5 为角度有效、正在调头、允许调头、允许小陀螺自旋、上板已选中小陀螺、升降低位禁止云台模式。下板仅在 C1 未超时且收到上板许可时自旋；许可丢失后需重新操作右拨杆，键鼠需退出再进入模式。`0xC2` 字节 0 为 `0xA6`，字节 1 bit0 为升降校准锁车，字节 2 为请求序号。C1/C2 均有独立超时；FDCAN2 进入 Bus-Off 时，`Communication_Service()` 限频 Stop/Start 恢复，相关计数可在调试器查看。

## 超级电容与无线充

FDCAN1 的统一 `ChassisCan_Send()` 和 FIFO0 回调同时服务四轮电机、电容和无线充。`0x211` 为电容状态（兼容 7/8 字节），`0x212` 为无线充状态；分别存入 `power_communication_state.capacitor` / `.wireless`，并分别按反馈时间判在线。`0x222` 是电容基础控制帧，默认每 20 ms 发送一次，包含固定功率字段与使能/预充/Turbo 标志。当前未接入裁判系统的动态功率限制，`online` 只是对应设备近期有回报，不代表无线充必须正在充电。

## 完整操作映射与细节

| 输入 | 下板行为 | 两板配合的限制 |
| --- | --- | --- |
| 左拨杆上/中/下 | 跟随/机械/机械；左下仍允许正常底盘移动 | 上板左下开放升降、关闭发射；校准阶段的 C2 锁车例外。 |
| 右拨杆下/中/上 | 普通模式下控制发射；小陀螺中右上档使能自旋 | 上板在小陀螺中禁止发射，退出后须重新布防；下板自旋仍等待上板 C1 许可。 |
| 拨轮正向 | 切换小陀螺选中状态 | 必须先回中；启用前右拨杆处于下档。小陀螺自旋时仍可按云台正方向控制平移。 |
| 拨轮中位→负向 | 发出一次调头请求 | 先停车等待上板 Yaw 接管约 180°，完成即解除；超时撤销。调头不是把机械零点重设为车尾。 |
| 左下且右拨杆中/下 | 下板继续机械底盘控制 | 上板将其解释为升降高/低位；须进入左下后再换右拨杆档，且校准、对准与 Pitch 安全条件均满足。 |

| 键鼠输入 | 作用 | 生效细节 |
| --- | --- | --- |
| `V`；`Z` / `X` | 接管开关；跟随 / 机械 | `V` 切换时重置模式和陀螺锁存。 |
| `W/S`、`A/D`、`Shift`、`Ctrl` | 前后、左右、加速、减速 | 下板映射平移通道，速度由灵敏度结构体配置。 |
| 鼠标 X/Y、右键 | 云台 Yaw/Pitch 输入；降低瞄准灵敏度 | 下板本地映射供底盘模式使用；板间转发的是原始 DBUS，上板独立映射。 |
| `G`、`Q` | 小陀螺切换、调头 | 按下沿触发，松开后才接受下一次。 |
| `F`、鼠标左键 | 摩擦轮开关、单发/连发 | 上板处理；左键短按单发，按住超过 200 ms 连发；小陀螺模式禁止发射。 |
| 机械模式 `B` | 升降高/低位切换 | 上板处理；仍须满足校准、Yaw/Pitch 安全条件。 |

断控清除键位边沿状态，不能把物理遥控的右拨杆保险条件误套到键鼠射击。

## 开发中遇到的问题与当前处理

| 表现 | 原因或定位要点 | 当前处理、复查位置 |
| --- | --- | --- |
| 上板重启后偶发收不到遥控，CAN 超时不能自恢复 | H7 双 FDCAN 共用 Message RAM，滤波、FIFO、通知或 Bus-Off 后恢复任一环节错误均可能断链 | FDCAN1 电机/超电、FDCAN2 板间分开初始化和过滤；板间仅收 C1/C2，`Communication_Service()` 处理 Bus-Off 限频恢复；看 D1～D3 发送计数和上板接收计数。 |
| 遥控开机后拨盘离线而底盘/摩擦轮正常 | 上板 CAN1 的 4005 反馈/命令时序、发射任务执行时间问题，不能直接归因于下板遥控带宽 | 下板转发 D1～D3 周期已设为 4 tick；不要额外高频重复发遥控帧。上板对照 `dial_motor_feedback.rx_count`、射击任务超期与 CAN1 收发间隔。 |
| 超电通信影响底盘控制、无线充不在线 | FDCAN1 周期帧过密会与电机抢发送时隙；无线充没有上电/没有状态帧时 `online=0` 是可能的 | 电机、超电、无线充统一经 `chassis_can` 发送/回调分发；`0x222` 控制帧默认 20 ms，`0x211/0x212` 分开判在线；不要把无线充在线等同于正在充电。 |
| 跟随慢、Yaw 越转越偏，或小陀螺后切模式绕远 | 车体机械角、反向车头选择、上板 IMU 稳向和速度前馈的坐标/符号耦合 | C1 发归中后的机械相对角，下板选最近的 0°/180° 车头并用角误差比例 + 输入前馈跟随；平移按云台朝向旋转。先核角度符号、限幅与斜坡，不用下板加速度积分速度作闭环。 |
| 调头完成后一段时间底盘仍锁车 | 请求预锁与“正在调头”标志被错误延用 | 当前预锁等上板确认，C1 报完成即解除；未确认按 `turn_ack_timeout_ms` 撤销。校准 C2 锁车有独立有效期，不能和调头锁车混成一个长期状态。 |
| 升降时车轮曾被要求绝对静止，回退要晃动底盘才成功 | 旧锁车确认/电流条件耦合了升降流程 | 当前只在上电找顶**校准阶段**响应 C2 锁车；普通升降不限制底盘移动。校准异常应先看上板 2006 反馈/堵转状态及 C2 有效期。 |
| 改任务周期后控制变慢或堵转判据改变 | “每 N 个任务周期”不是固定毫秒；PID、斜坡、超时可能仍按旧周期配置 | 底盘控制当前 4 tick，板间 4 tick，解析 15 tick；更改周期时一并核对 PID `control_period_s`、斜坡每周期增量、上板 D1～D3 拼帧时限及电机心跳。 |
| 整车短时完全不受控 | 历史上曾由电池电压不足造成，不一定是 CAN 或状态机 | 排查顺序：电源与电机使能 → DBUS 有效帧计数 → 两板 C1/D1～D3 在线 → FDCAN 接收/Bus-Off → PID 输出。 |

## 后续开发注意事项

| 变更类型 | 必须同步检查 |
| --- | --- |
| 新增 FDCAN1 设备 | 四轮 `0x200`、超电 `0x211/0x222`、无线充 `0x212` 共总线；核 ID、滤波器、FIFO 和发送频率，不能阻塞电机任务。FDCAN2 只承担板间通信。 |
| 修改板间协议 | DBUS 拼帧、C1/C2/D1～D5 或锁车握手要两板同步维护字节序、单位、有效位、序号、超时和滤波器；分别编译、成对烧录，并测试断控后边沿保险。 |
| 在线调参或改任务周期 | `application_config.[ch]` 放策略与灵敏度，`peripheral_config.[ch]` 放驱动 PID/离线阈值/协议周期；默认值仅在 `main.c` 初始化一次。改变 tick 周期时重算所有按周期计数的参数。 |
| 调整坐标与跟随 | 底盘目标是转子 rpm，C1 是 `0.01°`，D4 是 `0.01°/s`；最近车头与小陀螺方向须统一符号。当前跟随不是 IMU 速度 PID，也不是加速度积分平移闭环。 |
| CubeMX 重新生成及上板 | 复核双 FDCAN Message RAM/FIFO/中断、UART DMA、SPI、任务创建和 Keil 路径；驱动放 `bottom_driven`，底盘策略放 `user/chassis`。台架先验证断控、失联、锁车超时和电机方向。 |
