# 参数配置

- `application_config.h`：应用参数类型与变量。
- `application_config.c`：按部件、模式和功能加载应用默认值。
- `peripheral_config.h`：驱动参数类型、反馈结构体引用和模块入口索引。
- `peripheral_config.c`：驱动默认参数与分类初始化函数。

默认值在启动时统一加载。确认调参效果后修改对应分类初始化函数；多字段修改请停机完成。

底盘四个电机分别在 `motor3508_config.wheel[0..3]` 调整位置 PID、速度 PID 和固定扭矩前馈；各轮默认值集中在 `Motor3508WheelConfig_Init()` 的 ID 块内。

完整成员、单位和初始化入口见 [配置与调参](../文档/11_配置与调参.md)。驱动和算法的结构体访问见 [模块接口与目录](../文档/12_模块接口与目录.md)。

常用运行变量、单位和排查顺序见 [观察变量速查](../文档/00_观察变量速查.md)，各模块表中可直接复制完整 Watch 表达式。
